# 독서 타이머 및 주간 출석 정책

## 개요

- 기준일: 2026-08-21
- 적용 대상: `활성` 상태의 로그인 회원
- 적용 화면: `/timer`, 활성 세션이 있는 `/` 홈 화면
- 목적: 서버에서 측정한 독서 시간을 날짜별로 누적하고 월요일부터 일요일까지의 주간 출석 현황을 제공합니다.

## 핵심 기준

| 항목 | 기준 |
| --- | --- |
| 일일 출석 | 하루 누적 유효 독서 시간이 600초 이상인 경우 |
| 주간 범위 | 월요일 00:00부터 일요일 23:59:59까지 |
| 기준 시간대 | `Asia/Seoul` |
| 동시 실행 | 회원당 활성 타이머 1개 |
| 세션 최대 인정 시간 | 28,800초(8시간) |
| 목표시간 자동 완료 | 미설정 또는 1분 이상 8시간 이하, 목표 도달 시 완료 및 알림 |
| 책 연결 | 본인의 `읽는 중` 상태 독후감만 선택 가능하며 미선택도 허용 |
| 공개 범위 | 로그인 회원 본인만 조회 가능 |

주간 출석은 별도 보상이나 주간 성공 조건을 두지 않고 `출석 일수/7일`로 표시합니다. 여러 세션의 유효 독서 시간은 날짜별로 합산하며 자정을 넘긴 측정 구간은 각 날짜에 실제 포함된 초 단위로 나눕니다.

## 타이머 상태

| 상태 | 코드 | 처리 기준 |
| --- | --- | --- |
| 측정 중 | 실행 중 | 최근 시작 시각부터 서버 시간을 기준으로 독서 시간을 계산합니다. |
| 일시정지 | 일시 중지 | 직전 측정 구간을 날짜별 누적값에 반영하고 이후 시간은 제외합니다. |
| 완료 | 완료 | 마지막 측정 구간을 반영하고 더 이상 재개할 수 없습니다. |

- 시작 요청에 이미 활성 타이머가 있으면 새 세션을 만들지 않고 기존 세션을 반환합니다.
- 같은 상태 변경 요청이 반복되면 중복 누적하지 않고 현재 결과를 반환합니다.
- 다른 회원의 세션 번호나 본인 소유가 아닌 독후감 번호는 처리하지 않습니다.
- 브라우저가 계산한 누적 시간과 시각은 저장 기준으로 사용하지 않습니다.
- 화면은 서버 응답 시각과 확정 누적 시간을 기준으로 초 표시만 보간합니다.
- 네트워크 연결이 없으면 신규 타이머를 시작할 수 없으며, 진행 중인 화면은 연결 복구 후 서버 상태로 다시 맞춥니다.
- 목표시간은 세션 시작 시 알림 목표 독서 시간 초에 저장하며 설정하지 않은 세션도 허용합니다.
- 실행 중인 목표 알림 예정 일시는 목표시간 알림 예정 일시, 실제 알림 저장 성공 일시는 알림 발송 일시에 기록합니다.
- 일시정지하면 목표시간 알림 예정 일시를 비우고, 재개하면 확정 독서시간을 제외한 남은 목표시간으로 다시 계산합니다.
- 목표 알림을 한 번 발송한 세션은 일시정지 후 재개해도 다시 예약하지 않습니다.
- 목표시간에 도달하면 목표 종료시각까지의 측정 구간을 날짜별 누적값에 반영하고 세션을 `완료(COMPLETED)` 상태로 자동 종료합니다.
- 열린 타이머 화면과 홈 플레이어는 남은 시간이 0초가 되면 자동 완료 API를 호출하며, 화면이 닫힌 경우에도 서버 스케줄러가 최대 10초 주기로 같은 완료 처리를 보장합니다.
- 스케줄러 실행이 늦어져도 목표 종료시각 이후의 지연 시간은 독서시간에 포함하지 않습니다.
- 자동 완료 저장과 알림 저장은 별도 트랜잭션으로 처리하며, 알림 저장에 실패해도 완료 상태와 확정 독서시간은 유지합니다.
- 자동 완료 뒤 알림 저장에 실패하면 목표시간 알림 예정 일시를 유지해 다음 스케줄러 주기에 알림만 재시도하고, 성공 시 알림 발송 일시를 기록하며 예약을 해제합니다.

## 화면 정책

타이머 화면은 이번 주 출석, 현재 타이머와 연결할 책, 연도별 독서 잔디 및 도서별 누적 독서 시간 순서로 제공합니다.

- 이번 주 출석은 월요일부터 일요일까지 일곱 날짜와 출석 여부를 표시합니다.
- 오늘 누적 독서시간은 별도 카드 없이 이번 주 출석 제목 오른쪽에 분 단위로 표시합니다.
- 오늘은 출석 여부와 별개로 현재 날짜임을 구분합니다.
- 진행 중인 타이머는 다른 화면으로 이동하거나 화면을 새로 열어도 서버의 활성 세션을 기준으로 복원합니다.
- 홈 화면은 실행 중 또는 일시 중지 활성 세션이 있을 때 독후감 등록 버튼 왼쪽에 음악 플레이어 형태의 타이머를 표시합니다. 플레이어에는 연결 도서가 있으면 표지, 현재 시간, 도서 제목을 표시하며 일시정지·재개·정지 저장 명령을 제공합니다.
- 홈 타이머 플레이어는 흰색 반투명 배경과 배경 흐림, 독후감 등록 버튼과 같은 둥근 모서리 및 회색 테두리를 사용합니다. 도서 없이 시작한 세션은 표지 영역을 표시하지 않고 도서 미연결 상태를 안내합니다.
- 홈 플레이어의 정지 저장은 세션을 완료로 변경하고 서버가 마지막 측정 구간과 날짜별 누적값을 저장한 뒤 플레이어를 아래 방향으로 내리며 제거합니다.
- 홈 플레이어의 일시정지·재개·완료 결과는 타이머 화면과 하단 네비게이션이 사용하는 공통 타이머 요약 캐시에 즉시 반영합니다.
- 활성 세션이 없는 최초 화면의 타이머 시간은 오늘 누적시간과 분리해 항상 `00:00:00`으로 표시합니다.
- 시작 전 실행 버튼 영역은 왼쪽 `타이머 설정`, 오른쪽 `독서 시작`을 같은 너비로 배치합니다.
- 타이머 설정 모달은 시간과 분을 입력하며 기본 선택값은 30분, 최대 선택값은 8시간입니다.
- 하단 네비게이션의 타이머 아이콘은 활성 세션이 실행 중일 때 알림 아이콘과 같은 빨간 점을 우측 상단에 표시하고 일시 중지 또는 완료일 때 숨깁니다.
- 앱 진입과 창 포커스 복귀 시 서버의 활성 세션을 다시 확인하며, 현재 앱에서 시작·일시정지·재개·완료한 결과는 네비게이션에 즉시 반영합니다.
- 연도별 독서 잔디는 마이페이지와 같은 가로 스크롤 동작을 사용하며 안내 문구는 최초 조작 후 천천히 숨깁니다. 가로 스크롤바는 조작 중에 표시하고 마지막 조작이 끝난 뒤 지연 페이드아웃합니다.
- 현재 읽는 책이 있으면 선택할 수 있고 책을 선택하지 않은 측정도 허용합니다.
- 현재 읽는 책 선택 팝업은 `읽는 중` 상태 독후감 유무와 관계없이 도서 목록 또는 빈 상태 영역 아래 2px 위치의 우하단에 회색 `도서 검색하기`와 우측 화살표 명령을 표시합니다. 우측 상단 닫기는 독서 목표 설정 팝업과 같은 연회색 원형 `×` 명령을 사용합니다.
- 타이머에서 도서 검색으로 진입하면 공용 검색 화면에 타이머 진입 출처를 전달하며, 도서 선택 시 일반 독후감 등록 화면 대신 오늘부터 목표일까지 걸리는 일수를 설정하는 팝업을 바로 표시합니다.
- 타이머 전용 목표일 팝업은 별도 설명과 입력 항목명을 표시하지 않고 7일을 기본값으로 표시하며, 왼쪽 `-`, 오른쪽 `+` 버튼으로 최소 1일까지 조정합니다. 시작일은 오늘이며 종료일은 오늘에 선택 일수를 더해 계산합니다. 하단은 독서 목표 설정 팝업과 같은 흰색 `닫기`와 검정색 `확인` 버튼을 같은 너비로 표시하고 단일 단계 화면에는 진행 표시를 두지 않습니다.
- 목표일 팝업을 닫으면 타이머로 돌아가 현재 읽는 책 선택 팝업을 다시 표시합니다.
- 기간 확인 시 선택 도서와 계산한 기간으로 `읽는 중` 상태 독후감을 등록합니다. 등록 성공 뒤 타이머 요약을 강제로 다시 조회하고 새 독후감 번호를 선택 상태로 전달해 현재 읽는 책 선택 팝업을 열린 상태로 유지하며 방금 추가한 책을 즉시 표시합니다.
- 읽는 중 상태의 도서가 없더라도 도서 없이 타이머를 시작할 수 있습니다.
- 오늘 완료한 타이머에 연결된 독후감이 있으면 도서 제목을 굵은 링크로 표시하고 누르면 해당 독후감 상세로 이동합니다.
- 도서별 누적 독서 시간은 보존 중인 완료 세션 중 확정 독서 시간이 1초 이상이고 도서가 연결된 기록만 도서 단위로 합산합니다.
- 도서별 누적 독서 시간 목록은 각 도서의 가장 최근 타이머 완료 일시 내림차순으로 표시하고, 완료 일시가 같으면 도서 번호 내림차순으로 순서를 고정합니다.
- 도서별 누적 독서 시간은 최초 20권을 조회하며, 사용자가 목록 하단에 도달하면 같은 정렬 기준의 다음 20권을 이어서 조회합니다.
- 도서별 누적 독서 시간 항목을 누르면 해당 도서의 가장 최근 완료 타이머에 연결된 본인 독후감 상세로 이동합니다.
- 완료된 세션 상세의 1년 보존기간이 지나면 해당 세션은 도서별 누적 독서 시간에서도 제외되며 별도 장기 도서별 집계는 저장하지 않습니다.
- 최대 인정 시간에 도달하면 이후 시간을 더하지 않고 종료하도록 안내합니다.
- 로딩, 조회 실패와 기록 없음 상태를 구분하여 표시합니다.

## 데이터 보존과 계정 수명주기

- 완료된 세션 상세는 종료일 기준 1년 동안 보존합니다.
- 날짜별 누적 독서 시간과 출석 데이터는 계정이 물리 삭제될 때까지 보존합니다.
- `비활성화`과 영구 탈퇴 대기 전환 시 진행 중이거나 일시정지된 세션을 즉시 완료로 종료하고 일반 타이머 화면과 API 접근을 중지합니다.
- 계정 상태 전환으로 완료하는 세션은 아직 발송하지 않은 목표시간 알림 예정 일시를 즉시 제거하며 복귀 또는 탈퇴 취소 뒤 자동 복원하지 않습니다.
- 목표시간으로 이미 자동 완료됐지만 알림을 재시도 중인 세션도 계정 비활성화 또는 영구 탈퇴 신청 시 목표시간 알림 예정 일시를 제거하고 알림을 더 이상 발송하지 않습니다.
- `비활성화`과 영구 탈퇴 대기 상태에서는 일반 네비게이션의 타이머 실행 표시와 홈 타이머 플레이어를 제공하지 않으며, 계정 복귀 후 새 활성 세션이 시작된 경우에만 다시 표시합니다.
- 계정 비활성화 복귀 또는 영구 탈퇴 취소 시 보존된 세션 상세와 날짜별 출석 이력을 다시 제공합니다.
- 계정 비활성화 복귀 또는 영구 탈퇴 취소 시 보존된 완료 세션을 기준으로 도서별 누적 독서 시간 목록을 20권 단위로 다시 제공합니다.
- 계정 복귀 또는 영구 탈퇴 취소 뒤 누적 목록의 독후감 이동은 보존된 본인 독후감 연결만 다시 제공하며, 독후감의 접근·공개·보존·삭제는 기존 독후감 정책을 그대로 따릅니다.
- 유예기간이 끝나 회원이 물리 삭제되면 독서 타이머 세션과 일별 독서 시간 집계의 회원 데이터를 모두 삭제하며 복구하지 않습니다.
- 알림 목표 독서 시간 초, 목표시간 알림 예정 일시, 알림 발송 일시는 세션 상세와 같은 1년 보존 기준을 따르며 세션 물리 삭제 때 함께 삭제합니다.
- 이미 생성된 독서 타이머 기간 초과 알림은 기존 알림 삭제·비활성화·복원 정책을 따릅니다.
- 타이머 데이터는 독후감 공개 여부, 댓글, 알림, 푸시 구독 및 소셜 관계를 변경하지 않습니다.
- 타이머의 도서 검색 흐름에서 생성한 `읽는 중` 독후감은 기존 독후감과 동일하게 비공개 `N`, 평점 `0`으로 저장하며 별도 알림 또는 소셜 활동을 생성하지 않습니다.
- `비활성화`과 영구 탈퇴 대기 상태에서는 타이머, 도서 검색 및 해당 경로의 독후감 등록을 모두 차단합니다. 복귀 또는 탈퇴 취소 시 보존된 독후감만 기존 범위로 다시 제공하며 제한 중 입력하던 검색 도서와 미확정 기간은 복원하지 않습니다.
- 연결된 독후감이 먼저 삭제되면 세션의 독후감 번호만 제거하고 독서 시간은 유지합니다.

상세 계정 기준은 [회원 탈퇴 정책](withdrawal-policy.md)을 따릅니다.

## API와 서버 검증

| API | 용도 |
| --- | --- |
| `GET /api/reading-timer/summary` | 활성 타이머, 이번 주 출석, 오늘 누적 시간, 현재 읽는 책과 최근 세션 조회 |
| `GET /api/reading-timer/book-times?page={page}` | 최근 완료 기록순 도서별 누적 독서 시간을 20권 단위로 조회 |
| `POST /api/reading-timer/sessions` | 신규 타이머 시작 또는 기존 활성 타이머 복원 |
| `PATCH /api/reading-timer/sessions/{tmrxNumb}` | 타이머 일시정지, 재개 또는 완료 |

- 상태 변경 요청은 인증 회원 번호와 경로의 타이머 번호를 함께 검증합니다.
- 세션 시작과 상태 변경은 회원 행 잠금을 사용하여 여러 기기의 동시 요청을 직렬화합니다.
- 세션 상태 변경과 날짜별 누적값 반영은 하나의 트랜잭션으로 처리합니다.
- 목표시간이 지난 상태 변경 요청은 요청한 상태보다 자동 완료를 우선하며 목표 종료시각까지만 확정합니다.
- 일일 출석 여부는 저장된 누적 초와 진행 중 구간의 조회 시점 예상값을 합산하여 계산합니다.
