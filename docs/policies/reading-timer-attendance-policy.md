# 독서 타이머 및 주간 출석 정책

## 개요

- 기준일: 2026-08-14
- 적용 대상: `ACTIVE` 상태의 로그인 회원
- 적용 화면: `/timer`
- 목적: 서버에서 측정한 독서 시간을 날짜별로 누적하고 월요일부터 일요일까지의 주간 출석 현황을 제공합니다.

## 핵심 기준

| 항목 | 기준 |
| --- | --- |
| 일일 출석 | 하루 누적 유효 독서 시간이 600초 이상인 경우 |
| 주간 범위 | 월요일 00:00부터 일요일 23:59:59까지 |
| 기준 시간대 | `Asia/Seoul` |
| 동시 실행 | 회원당 활성 타이머 1개 |
| 세션 최대 인정 시간 | 14,400초 |
| 책 연결 | 본인의 `READ` 상태 독후감만 선택 가능하며 미선택도 허용 |
| 공개 범위 | 로그인 회원 본인만 조회 가능 |

주간 출석은 별도 보상이나 주간 성공 조건을 두지 않고 `출석 일수/7일`로 표시합니다. 여러 세션의 유효 독서 시간은 날짜별로 합산하며 자정을 넘긴 측정 구간은 각 날짜에 실제 포함된 초 단위로 나눕니다.

## 타이머 상태

| 상태 | 코드 | 처리 기준 |
| --- | --- | --- |
| 측정 중 | `RUNNING` | 최근 시작 시각부터 서버 시간을 기준으로 독서 시간을 계산합니다. |
| 일시정지 | `PAUSED` | 직전 측정 구간을 날짜별 누적값에 반영하고 이후 시간은 제외합니다. |
| 완료 | `COMPLETED` | 마지막 측정 구간을 반영하고 더 이상 재개할 수 없습니다. |

- 시작 요청에 이미 활성 타이머가 있으면 새 세션을 만들지 않고 기존 세션을 반환합니다.
- 같은 상태 변경 요청이 반복되면 중복 누적하지 않고 현재 결과를 반환합니다.
- 다른 회원의 세션 번호나 본인 소유가 아닌 독후감 번호는 처리하지 않습니다.
- 브라우저가 계산한 누적 시간과 시각은 저장 기준으로 사용하지 않습니다.
- 화면은 서버 응답 시각과 확정 누적 시간을 기준으로 초 표시만 보간합니다.
- 네트워크 연결이 없으면 신규 타이머를 시작할 수 없으며, 진행 중인 화면은 연결 복구 후 서버 상태로 다시 맞춥니다.

## 화면 정책

타이머 화면은 이번 주 출석, 현재 타이머, 연결할 책, 오늘 누적 시간과 오늘 완료한 타이머 순서로 제공합니다.

- 이번 주 출석은 월요일부터 일요일까지 일곱 날짜와 출석 여부를 표시합니다.
- 오늘은 출석 여부와 별개로 현재 날짜임을 구분합니다.
- 진행 중인 타이머는 다른 화면으로 이동하거나 화면을 새로 열어도 서버의 활성 세션을 기준으로 복원합니다.
- 하단 네비게이션의 타이머 아이콘은 활성 세션이 `RUNNING`일 때 알림 아이콘과 같은 빨간 점을 우측 상단에 표시하고 `PAUSED` 또는 `COMPLETED`일 때 숨깁니다.
- 앱 진입과 창 포커스 복귀 시 서버의 활성 세션을 다시 확인하며, 현재 앱에서 시작·일시정지·재개·완료한 결과는 네비게이션에 즉시 반영합니다.
- 최근 완료된 타이머 영역은 `Asia/Seoul` 기준 오늘 00:00 이상 내일 00:00 미만에 완료된 본인 타이머를 최신 완료 순으로 모두 표시합니다.
- 현재 읽는 책이 있으면 선택할 수 있고 책을 선택하지 않은 측정도 허용합니다.
- 읽는 중 상태의 도서가 없으면 도서 선택 상자를 표시하지 않고 도서 없이 타이머를 시작할 수 있습니다.
- 오늘 완료한 타이머에 연결된 독후감이 있으면 도서 제목을 굵은 링크로 표시하고 누르면 해당 독후감 상세로 이동합니다.
- 최대 인정 시간에 도달하면 이후 시간을 더하지 않고 종료하도록 안내합니다.
- 로딩, 조회 실패와 기록 없음 상태를 구분하여 표시합니다.

## 데이터 보존과 계정 수명주기

- 완료된 세션 상세는 종료일 기준 1년 동안 보존합니다.
- 날짜별 누적 독서 시간과 출석 데이터는 계정이 물리 삭제될 때까지 보존합니다.
- `WITHDRAWN`과 `DELETE_PENDING` 전환 시 진행 중이거나 일시정지된 세션을 즉시 `COMPLETED`로 종료하고 일반 타이머 화면과 API 접근을 중지합니다.
- `WITHDRAWN`과 `DELETE_PENDING` 상태에서는 일반 네비게이션의 타이머 실행 표시를 제공하지 않으며, 계정 복귀 후 새 `RUNNING` 세션이 시작된 경우에만 다시 표시합니다.
- 계정 비활성화 복귀 또는 영구 탈퇴 취소 시 보존된 세션 상세와 날짜별 출석 이력을 다시 제공합니다.
- 유예기간이 끝나 회원이 물리 삭제되면 `TM_RDTMRX`와 `TB_RDATDX`의 회원 데이터를 모두 삭제하며 복구하지 않습니다.
- 타이머 데이터는 독후감 공개 여부, 댓글, 알림, 푸시 구독 및 소셜 관계를 변경하지 않습니다.
- 연결된 독후감이 먼저 삭제되면 세션의 `REPT_NUMB`만 제거하고 독서 시간은 유지합니다.

상세 계정 기준은 [회원 탈퇴 정책](withdrawal-policy.md)을 따릅니다.

## API와 서버 검증

| API | 용도 |
| --- | --- |
| `GET /api/reading-timer/summary` | 활성 타이머, 이번 주 출석, 오늘 누적 시간, 현재 읽는 책과 최근 세션 조회 |
| `POST /api/reading-timer/sessions` | 신규 타이머 시작 또는 기존 활성 타이머 복원 |
| `PATCH /api/reading-timer/sessions/{tmrxNumb}` | 타이머 일시정지, 재개 또는 완료 |

- 상태 변경 요청은 인증 회원 번호와 경로의 타이머 번호를 함께 검증합니다.
- 세션 시작과 상태 변경은 회원 행 잠금을 사용하여 여러 기기의 동시 요청을 직렬화합니다.
- 세션 상태 변경과 날짜별 누적값 반영은 하나의 트랜잭션으로 처리합니다.
- 일일 출석 여부는 저장된 누적 초와 진행 중 구간의 조회 시점 예상값을 합산하여 계산합니다.
