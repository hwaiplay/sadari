# 최초 로그인 웰컴, 관심분야 및 닉네임 정책

## 개요

- 목적: 신규 회원에게 Sadari의 주요 기능을 소개하고 독서 관심분야를 선택할 기회와 서비스에서 사용할 닉네임 확정 절차를 제공합니다.
- 적용 대상: Kakao 로그인으로 신규 등록되어 `사용자 계정과 프로필의 온보딩 완료 여부 = 'N'`인 회원입니다.
- 기준일: 2026-08-28

## 정상 흐름

1. 신규 회원을 등록할 때 중복되지 않는 랜덤 닉네임을 발급하고 온보딩 완료 여부를 `N`으로 저장합니다.
2. 인증 확인 응답이 온보딩 미완료 상태이면 일반 서비스 화면보다 `/welcome`로 먼저 이동합니다.
3. 웰컴 화면은 관리자가 현재 배포한 페이지의 소제목, 제목, 설명과 이미지를 노출 순서대로 표시합니다.
4. 관리자 페이지 수와 관계없이 상단 로고와 현재·전체 페이지 수, 하단 진행 표시와 이전·다음 버튼은 애플리케이션이 고정해 표시합니다.
5. 관리자 페이지 뒤에는 가입 시 발급한 랜덤 닉네임 확인·수정 페이지와 관심분야 설정 페이지를 이 순서로 항상 고정합니다.
6. 닉네임 페이지에서 사용자는 기본 닉네임을 유지하거나 수정한 뒤 다음 단계로 이동합니다.
7. 마지막 관심분야 페이지에는 공지사항 카테고리 분류의 활성 1뎁스 대분류별로 그 하위 관심분야를 나누어 항상 표시합니다.
8. 각 대분류의 첫 선택 항목은 해당 대분류 전체 선택 및 해제를 처리하고, 모든 소분류를 개별 선택해도 전체 선택 상태로 표시합니다.
9. 마지막 페이지는 닉네임 단계에서 확정한 닉네임과 함께 관심분야를 2개 이상 선택하도록 안내합니다.
10. 사용자는 관심분야를 2개 이상 선택한 뒤 화면 하단의 시작하기를 누르며, 선택 개수가 부족하면 경고를 표시하고 완료 처리를 중단합니다.
11. 선택한 관심분야는 별도 요청으로 회원 독서 관심분야를 전체 교체합니다.
12. 서버는 닉네임과 온보딩 완료 여부를 한 트랜잭션으로 저장합니다.
13. 인증 상태를 다시 조회한 뒤 홈 화면으로 이동합니다.

## 관리자 콘텐츠 관리

- 관리 메뉴는 `관리자 > 컨텐츠 관리 > 웰컴페이지 관리`입니다.
- 관리자는 소제목, 제목, 설명, 이미지와 노출 순서를 입력해 페이지를 추가하고 특정 버전을 배포할 수 있습니다.
- 이미지는 관리자 화면에서 JPG 또는 PNG 파일로 등록하며 검증과 재인코딩이 끝난 공개 경로만 콘텐츠에 저장합니다.
- 관리자 미리보기는 현재 편집값과 등록된 관리 페이지를 노출 순서대로 표시하며, 사용자 화면과 같은 로고, 페이지 번호, 진행 표시와 이전·다음 버튼을 제공합니다.
- 미리보기의 이전·다음 및 진행 표시 버튼은 등록된 관리 페이지 사이를 이동하며 고정 닉네임과 관심분야 페이지는 미리보기에 포함하지 않습니다.
- 현재 배포본을 수정하면 사용자 노출 내용을 보존한 채 다음 미배포 버전을 생성하고, 미배포본 재저장은 같은 버전을 수정합니다.
- 같은 페이지 주키에는 현재 배포 버전을 하나만 허용합니다.
- 관리자 콘텐츠는 계정별 데이터가 아니므로 회원 탈퇴와 복귀에 따라 삭제하거나 복원하지 않습니다.
- 신규 홍보 문구와 실제 화면 캡처 이미지는 후보 승인 후 반영할 예정이며 현재 정책 적용 범위에는 포함하지 않습니다.

## 닉네임 검증

- 닉네임은 25자 이하로 입력합니다.
- 한글, 영문, 숫자를 사용할 수 있습니다.
- 공백은 사용할 수 없습니다.
- 문자 사이에 단일 언더바 또는 하이픈을 사용할 수 있습니다.
- 앞뒤 또는 연속 구분자는 허용하지 않습니다.
- 정책 변경 전에 저장된 공백 포함 닉네임은 일괄 변경하지 않습니다.
- 다른 회원과 중복되거나 비속어가 포함된 닉네임은 저장하지 않습니다.
- 프론트엔드 검증을 통과하더라도 서버에서 같은 규칙을 다시 검증합니다.

## 접근 및 실패 처리

- 온보딩 미완료 회원이 일반 보호 경로에 접근하면 `/welcome`로 이동합니다.
- 온보딩 완료 회원이 `/welcome`에 직접 접근하면 `/home`으로 이동합니다.
- 영구 삭제 대기 상태는 온보딩보다 우선하며 탈퇴 취소 전용 화면으로 이동합니다.
- 비활성, 정지 및 영구 삭제 대기 회원에게는 현재 배포 웰컴페이지 조회를 허용하지 않습니다.
- 계정 비활성화와 복귀 전후에도 사용자 계정과 프로필의 기존 온보딩 완료 상태를 유지합니다.
- 닉네임 저장에 실패하면 온보딩 완료 여부를 변경하지 않고 현재 화면에서 재시도할 수 있습니다.
- 관심분야 조회에 실패하거나 2개 미만을 선택한 경우에는 온보딩 완료 처리를 시작하지 않습니다.
- 관심분야 저장에 실패하면 닉네임과 `온보딩 완료 여부 = 'Y'` 저장을 진행하지 않고 현재 화면에서 재시도할 수 있습니다.
- DB 저장이 완료된 뒤에만 Redis의 로그인 사용자 닉네임을 갱신합니다.

## 데이터 기준

| 대상 | 값 | 의미 |
| --- | --- | --- |
| 사용자 계정과 프로필의 온보딩 완료 여부 | `N` | 최초 로그인 웰컴과 닉네임 확정 필요 |
| 사용자 계정과 프로필의 온보딩 완료 여부 | `Y` | 온보딩 완료 |
| 사용자 계정과 프로필의 사용자 닉네임 | 문자열 | 가입 시 발급하거나 사용자가 확정한 닉네임 |
| 회원 독서 관심분야 | 회원·분류값 조합 | 최초 로그인에서 선택한 공지사항 카테고리 분류 하위 독서 관심분야. 웰컴 완료 시 2개 이상 저장 |
| 웰컴페이지 콘텐츠 | 페이지 주키·버전 | 소제목, 제목, 설명, 이미지, 노출 순서, 현재 배포 여부 및 등록·수정·배포 관리 정보 |

기존 회원은 기능 적용 시 `온보딩 완료 여부 = 'Y'`로 이관하며, 이후 신규 회원의 기본값은 `N`입니다.
