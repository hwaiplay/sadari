# 독서 및 독후감 정책

## 도서와 독후감 등록

- 사용자가 카카오 도서 검색 결과를 선택해 독후감을 등록합니다.
- ISBN 기준 도서 정보가 `TM_BKINFO`에 없으면 도서 정보를 먼저 등록합니다.
- 도서 등록과 회원 독후감 등록은 하나의 업무 흐름으로 처리합니다.
- 도서 제목, 작가, 출판사, ISBN, 표지, 설명은 등록 필수 도서 정보입니다.
- 작가 문자열에 포함된 `^` 구분 문자는 저장 전에 정상 표시 문자열로 정리합니다.
- 신규 독후감의 책장 색상은 선택한 카카오 도서 표지의 대표색을 분석하여 자동으로 설정합니다.
- 표지 대표색과 사용 중인 `BOOK_COLR` 공통코드를 CIELAB 색상 거리로 비교하여 가장 가까운 색상을 선택합니다.
- 표지 분석에 실패하면 `BOOK_COLR` 정렬 순서가 가장 빠른 사용 중 색상을 기본값으로 설정합니다.
- 독후감 수정 시에는 기존에 저장된 책장 색상을 유지합니다.

## 독서 상태

`READ_STAT` 공통코드에 등록된 활성 코드만 저장할 수 있습니다.

| 코드 | 표시명 | 의미 |
| --- | --- | --- |
| `READ` | 읽고 있어요 | 독서 진행 중 |
| `DONE` | 다 읽었어요 | 독서 완료 |
| `STOP` | 중단했어요 | 독서 중단 |

- `DONE` 또는 `STOP`으로 빠르게 상태를 변경하면 저장일을 독서 종료일로 기록합니다.
- `READ` 상태에서는 기록만 선택적으로 입력할 수 있고 평점과 공개 여부를 선택할 수 없습니다.
- `READ` 상태의 평점은 미선택 값 `0`, 공개 여부는 비공개 `N`으로 강제 저장합니다.
- `DONE`과 `STOP` 상태에서는 독후감 기록이 필수입니다.
- `DONE`과 `STOP` 상태에서는 평점과 공개 여부를 선택할 수 있습니다.

## 독서 기간

- 시작일과 종료일은 등록 및 상세 직접 편집의 필수값입니다.
- 시작일은 종료일보다 늦을 수 없습니다.
- 화면에서는 하나의 기간 달력으로 시작일과 종료일을 선택합니다.
- 진행 상태는 `목표 독서 기간`, 완료 및 중단 상태는 `독서 기간`으로 표시합니다.
- 목표 종료일 초과 알림 대상은 별도 스케줄러 정책을 따릅니다.

## 별점

- 별점은 0점부터 5점까지 0.5점 단위로 저장할 수 있습니다.
- 0점은 사용자가 평점을 선택하지 않은 상태로 허용합니다.
- 평점이 비어 있으면 숫자 저장 일관성을 위해 0점으로 보정합니다.
- `READ` 상태에서는 평점 입력 화면을 표시하지 않으며 기존 평점도 0점으로 초기화합니다.
- `DONE`과 `STOP` 상태에서만 평점을 직접 수정할 수 있습니다.
- 별점은 클릭과 드래그 및 키보드 방향키로 0.5점씩 조정할 수 있습니다.
- 도서 평균 평점은 공개 여부와 관계없이 같은 ISBN의 `DONE`과 `STOP` 독후감을 기준으로 계산하며 `READ`는 제외합니다.

## 상세 직접 편집

- 별도의 독후감 수정 화면을 제공하지 않고 독후감 상세 화면에서 상태별 허용 항목과 기록을 직접 수정합니다.
- `READ` 상태는 독서 상태와 목표 독서 기간의 2열 요약을 표시하고, `DONE`과 `STOP` 상태는 공개 여부와 평점을 포함한 4열 요약을 표시합니다.
- 단계형 입력 팝업도 `READ` 상태에서는 공개 여부와 평점 단계를 제외하고, `DONE`과 `STOP` 상태에서는 네 단계를 모두 제공합니다.
- 요약 항목이나 기록을 처음 선택하면 삭제, 취소, 저장 명령을 표시합니다.
- 취소하면 마지막 서버 조회값으로 모든 입력을 복원합니다.
- 기록을 편집할 때만 현재 입력 바이트와 최대 허용 바이트를 표시합니다.
- 상세 조회 응답은 수정 가능한 독후감 원본의 SHA-256 내용 해시를 `editVersion`으로 제공합니다.
- 저장 요청은 조회 시점의 `editVersion`을 포함하고, 서버는 현재 DB 내용 해시와 같을 때만 수정합니다.
- 다른 탭이나 기기에서 먼저 수정해 해시가 달라지면 기존 내용을 덮어쓰지 않고 HTTP 409로 응답하며 최신 내용을 다시 확인하도록 안내합니다.

## 공개 여부

- 공개 여부는 `Y` 또는 `N`만 허용합니다.
- 값이 없으면 비공개 `N`을 기본값으로 적용합니다.
- `READ` 상태는 공개 여부 선택을 제공하지 않고 항상 비공개로 저장합니다.
- 공개 독후감 목록에는 공개 상태인 `DONE` 또는 `STOP` 독후감만 노출합니다.
- 마이페이지의 현재 읽는 책 빠른 완료 또는 중단 팝업에서는 평점과 공개 여부를 함께 선택할 수 있습니다.
- 다른 사용자 프로필의 독서 목록은 해당 화면의 공개 범위 정책에 따라 비공개 항목을 숨기거나 제한 표시합니다.
- 탈퇴 회원의 독후감은 모두 비공개로 전환합니다.

## 입력 검증

- 독후감 본문은 UTF-8 기준 최대 4,000바이트입니다.
- 본문은 HTML entity와 불필요한 표현을 일반 문자열로 정규화합니다.
- 본문에 차단 비속어가 포함되면 저장하지 않고 감지한 비속어를 사용자에게 안내합니다.
- 책장 색상은 `BOOK_COLR` 공통코드의 활성 값만 허용합니다.
- 사용자 번호와 독후감 번호를 함께 수정·삭제 조건으로 사용해 본인의 독후감만 변경할 수 있습니다.
- 독후감 삭제 시 해당 독후감 대상 좋아요도 함께 정리합니다.

## 목록과 검색

- 목록은 제목과 작가명으로 검색할 수 있습니다.
- 독후감 검색 결과가 없으면 같은 검색어를 도서 검색으로 이어갈 수 있습니다.
- 정렬은 종료일, 시작일, 평점 등의 허용된 정렬 코드만 사용합니다.
