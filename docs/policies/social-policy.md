# 소셜 정책

## 팔로잉 피드

- 피드는 로그인 사용자 본인과 현재 팔로우 중인 활성 회원의 공개 완독·중단 독후감 및 현재 프로필·배경사진 변경을 최신 활동순으로 제공합니다.
- 독후감 카드에는 도서 표지·제목·저자·상태·평점·내용을, 사진 변경 카드에는 해당 프로필 또는 배경 이미지를 표시합니다.
- 팔로우 이전에 공개된 독후감도 포함하며, 언팔로우하거나 작성자가 활성 상태가 아니면 다음 조회부터 제외합니다.
- 모든 피드 카드에서 좋아요와 댓글·답글을 사용할 수 있습니다.
- 독후감 알림 링크는 대상 유형과 번호로 공개 콘텐츠 한 건을 다시 검증해 해당 카드 또는 독후감 화면과 댓글 목록을 엽니다.

## 피드 사용자 검색

- 피드 헤더 하단의 고정 검색 입력에서 활성 회원의 닉네임을 부분 검색하며 로그인 사용자는 결과에서 제외합니다.
- 검색 결과에는 프로필 사진, 닉네임, 한줄소개와 로그인 사용자 기준 관계 버튼을 표시합니다.
- 양쪽이 서로 팔로우하는 친구, 한쪽 방향의 팔로우 관계가 있는 사용자, 관계가 없는 사용자 순으로 배치하며 같은 관계 그룹은 닉네임순으로 정렬합니다.
- 관계 버튼으로 팔로우 또는 언팔로우하면 서버가 확정한 최신 관계를 기준으로 첫 페이지부터 다시 정렬합니다.
- `비활성화(계정 비활성화)`, `영구 탈퇴 대기(영구 탈퇴 유예)` 및 `이용정지(이용 정지)` 회원은 보존된 팔로우 관계가 있어도 검색 결과에서 제외합니다.
- 비활성화 회원이 복귀하거나 영구 탈퇴를 취소해 정상 이용 상태가 되면 보존된 닉네임과 관계를 기준으로 다시 검색할 수 있습니다. 이용정지가 유지되면 검색 결과에 노출하지 않습니다.
- 유예기간 종료 후 물리 삭제된 회원은 사용자 원본과 관계가 삭제되므로 검색 결과와 관계 버튼의 대상에서 영구 제외합니다.

## 개요

- 목적: 다른 사용자 프로필과 소셜 상호작용에서 공개 데이터 범위, 집계 및 사용자 차단 기준을 일관되게 유지합니다.
- 적용 범위: 팔로우, 좋아요, 프로필 독서 요약, 사용자 차단 및 소셜 알림입니다.
- 기준일: 2026-08-27

## 사용자 차단 (정책 확정·기능 미구현)

- 사용자 차단은 아직 서버와 데이터베이스에 구현되지 않았으며 화면의 차단 명령도 실제 관계를 저장하지 않습니다.
- 향후 구현 범위와 프로필 사진·배경사진 반응 차단 기준은 [사용자 차단 기능 설계](../architecture/user-blocking-design.md)를 따릅니다.

- 사용자 차단은 방향이 있는 관계로 저장하지만, 어느 한쪽이라도 상대를 차단하면 양쪽 모두 개인 소셜 영역에서 서로 노출되지 않습니다.
- 차단한 상대와 상대가 차단한 사용자는 공개 프로필, 공개 독후감, 팔로잉 피드, 팔로우·팔로워 목록, 좋아요 사용자 목록과 일반 댓글·답글에서 서로 제외됩니다.
- 어느 한쪽도 상대를 팔로우하거나 상대 콘텐츠에 좋아요·댓글·답글을 새로 등록할 수 없습니다.
- 차단 시 두 사용자 사이의 팔로우 관계를 양방향 모두 삭제하며 차단을 해제해도 자동 복원하지 않습니다.
- 차단 자체로 기존 독후감, 댓글, 좋아요와 알림 이력은 삭제하지 않습니다. 보존된 댓글과 좋아요는 차단 기간의 공개 조회와 집계에서 제외하고 양방향 차단이 모두 해제되면 다시 포함합니다.
- 기존 알림은 유지하지만 차단 상대의 개인 영역으로 연결되는 링크는 현재 차단 관계를 확인해 접근을 거절합니다.
- 차단 이후 두 사용자 사이의 신규 개인 소셜 알림과 푸시는 생성하지 않습니다.
- 차단 사실, 차단한 사용자와 반대 방향 차단 존재 여부는 상대에게 제공하지 않습니다.
- 설정의 차단 사용자 관리에는 로그인 사용자가 직접 차단한 사용자만 표시하며 본인이 만든 차단 방향만 해제할 수 있습니다.
- 계정 비활성화와 영구 탈퇴 대기에는 차단 관계를 보존하고 복귀 시 그대로 적용합니다. 회원 원본이 물리 삭제되면 해당 회원의 양방향 차단 관계를 모두 삭제합니다.

### 독서 모임 예외

- 차단 관계여도 같은 독서 모임 참여와 제3자인 모임장의 초대·수락을 허용하며 차단만으로 기존 모임원을 자동 퇴장시키지 않습니다.
- 모임 회원, 운영자, 선정 도서, 투표, 회차와 모임 전용 독후감·댓글처럼 공동 운영에 필요한 정보는 차단 관계여도 표시합니다.
- 공동 콘텐츠에서 운영상 필요한 닉네임과 본문은 표시할 수 있지만 차단 상대의 공개 프로필로 이동하거나 상대를 대상으로 팔로우·좋아요·댓글·답글을 등록할 수 없습니다.
- 모임장과 운영자의 퇴장·제재·승계 권한은 개인 차단의 영향을 받지 않습니다.
- 모임장과 다른 모임원에게 차단 관계와 차단 방향을 공개하지 않습니다.
- 향후 모임 채팅의 시스템 메시지·공지와 일반 대화 표시 범위는 채팅 출시 전에 별도로 확정합니다.

## 팔로우 상태

팔로우 관계는 방향이 있는 관계로 저장합니다.

| 조건 | 버튼 상태 |
| --- | --- |
| 나만 상대를 팔로우함 | `FOLLOWING(팔로잉)` |
| 나는 팔로우하지 않고 상대만 나를 팔로우함 | `상호 팔로우 관계(맞팔로우)` |
| 양쪽 모두 팔로우하지 않음 | `FOLLOW(팔로우)` |
| 양쪽 모두 서로를 팔로우함 | `FRIEND(친구)` |

- `FRIEND(친구)` 버튼은 파란색 글자와 연한 하늘색 배경으로 표시합니다.
- 본인을 팔로우하는 요청은 허용하지 않습니다.
- 이미 존재하는 팔로우 요청은 중복 행을 만들지 않습니다.
- 언팔로우는 내가 상대를 팔로우한 방향만 삭제합니다.
- 상대가 나를 팔로우한 관계는 언팔로우 시 유지합니다.
- 새 팔로우 행이 실제로 생성된 경우에만 상대에게 알림을 생성합니다.
- 공개 독후감의 `관계순(기본순)`은 `FRIEND(친구)` 작성자, 로그인 사용자가 팔로우하는 작성자, 나머지 작성자 순으로 배치하고 같은 그룹은 최신순으로 정렬합니다.
- 사용자가 `최신순(최신순)`, `별점 내림차순(별점순)`, `좋아요 기능 설명(추천순)`을 선택하면 친구나 팔로우 관계를 반영하지 않고 선택한 기준만 적용합니다.
- 유지 중인 팔로우 관계라도 작성자가 `비활성화(계정 비활성화)`, `영구 탈퇴 대기(영구 탈퇴 유예)` 또는 `이용정지(이용 정지)`이면 해당 작성자의 독후감을 공개 목록과 우선 정렬에 사용하지 않습니다.

## 팔로우 및 팔로워 목록

- 마이페이지와 다른 사용자 프로필에서 팔로우 및 팔로워 목록을 제공합니다.
- 각 행에는 로그인 사용자 기준 팔로우 상태를 함께 제공합니다.
- 목록의 사용자가 로그인한 본인이면 팔로우 버튼을 표시하지 않습니다.
- `FRIEND(친구)` 관계인 회원을 SQL 정렬로 목록 상단에 우선 배치합니다.
- `이용정지(이용 정지)`, `비활성화(계정 비활성화)`, `영구 탈퇴 대기(영구 탈퇴 유예)` 회원은 회원 원본과 `사용자 팔로우 관계(팔로우 관계)`가 남아 있는 동안 목록에 노출합니다.
- 세 상태의 회원을 눌러 소셜 프로필에 진입하면 `사용자 계정 상태(회원 상태)` 코드와 코드명을 알림으로 표시하고, 사용자가 확인하면 이전 화면으로 이동합니다.
- 영구 탈퇴 유예기간이 지나 회원이 물리 삭제되면 양방향 `사용자 팔로우 관계(팔로우 관계)`를 삭제하고 팔로우·팔로워 목록에서도 완전히 제거합니다.
- 언팔로우 전에는 사용자 확인창을 표시합니다.

## 좋아요

- 좋아요는 대상 유형과 대상 번호 조합으로 대상을 식별합니다.
- 현재 사용자 기능에서 허용하는 대상은 독후감, 현재 프로필 사진, 현재 배경사진 및 각 대상에 작성된 댓글·답글입니다.
- 좋아요 요청은 등록과 취소를 토글 방식으로 처리합니다.
- 독후감 상세, 다른 사용자 독후감 둘러보기, 독서 모임 독후감, 피드, 마이페이지 사진 반응 및 댓글·답글에서 좋아요 숫자를 누르면 `좋아요 누른 사람` 목록을 표시합니다.
- 화면의 좋아요 수와 사용자 목록은 조회 시점에 정상 이용 중인 회원의 좋아요만 포함하며 두 값은 같은 서버 기준을 사용합니다.
- 계정 비활성화, 영구 탈퇴 대기 또는 이용 정지 상태의 회원은 좋아요 데이터가 남아 있어도 수와 목록에서 제외합니다.
- 제외된 회원이 정상 이용 상태로 복귀하고 좋아요 데이터가 보존되어 있으면 해당 좋아요를 수와 목록에 다시 포함합니다. 계정 처리 과정에서 삭제된 좋아요는 복원하지 않습니다.
- 좋아요 사용자 목록에는 프로필 사진, 닉네임과 한줄소개를 표시하며 로그인한 본인의 항목은 마이페이지로, 다른 회원의 항목은 공개 프로필로 이동합니다.
- 서버는 허용한 대상 유형과 현재 로그인 사용자의 대상 접근 권한을 확인한 뒤 좋아요 사용자 목록을 제공합니다.
- 좋아요를 새로 등록한 경우에만 독후감 작성자에게 알림을 생성합니다.
- 독후감 작성자가 해당 독후감의 좋아요 알림을 끈 경우 좋아요 행과 수 집계는 유지하고 신규 알림 저장과 푸시만 생략합니다.
- 좋아요 취소 시 알림을 새로 생성하지 않습니다.
- 본인이 작성한 독후감에 누른 좋아요는 본인에게 알림을 보내지 않습니다.
- 독후감 삭제 시 해당 독후감의 좋아요 데이터를 정리합니다.

## 프로필 및 배경사진 반응 공개 범위

- 정상 이용 중인 사용자의 현재 프로필 사진과 현재 배경사진은 팔로우 관계와 관계없이 다른 사용자의 공개 프로필에서 전체 화면으로 확인할 수 있습니다.
- 로그인한 정상 이용 사용자는 공개 프로필의 현재 프로필 사진과 배경사진에 좋아요를 등록·취소하고, 좋아요 사용자 목록과 댓글·답글을 조회·등록·수정·삭제할 수 있습니다.
- 서버는 요청할 때마다 사진 소유자와 로그인 사용자의 정상 이용 상태 및 사진 번호가 현재 프로필 또는 배경사진과 일치하는지 검증합니다.
- 사진이 교체되거나 삭제되면 이전 사진은 공개 프로필 반응 대상으로 사용할 수 없으며, 기존 정리 정책에 따라 사진 반응도 정리합니다.
- 팔로우 또는 언팔로우는 현재 사진의 공개 프로필 반응 접근 권한에 영향을 주지 않습니다.
- 사용자 차단 기능이 구현되면 차단 관계가 팔로우 여부보다 우선하며, 차단된 사용자 사이의 사진 조회와 반응을 모두 제한합니다.
- 프로필 또는 배경사진 변경을 팔로워 피드에 표시할지는 현재 일괄 동작을 유지하며 향후 [사용자 설정 정책](user-settings-policy.md)에 따라 선택 기능을 추가합니다.

## 프로필 공개 범위

- 다른 사용자 프로필에서 공개 독후감 기준 총 읽은 책과 받은 좋아요 수 및 팔로우와 팔로워 수를 제공합니다.
- 정상 이용 회원의 주간, 월간, 연간 독서 목표는 다른 사용자 프로필에 제공합니다.
- 다른 사용자 프로필의 총 읽은 책, 받은 좋아요, 독서량, 목표 달성 집계와 독서 목록에는 `독후감의 공개 여부 = 'Y'`인 공개 독후감만 반영합니다.
- `독후감의 공개 여부 = 'N'`인 비공개 독후감은 제목, 저자, 표지, ISBN, 기간 및 평점을 포함하여 다른 사용자 응답에 제공하지 않습니다.
- 본인 마이페이지의 독서 요약과 프로필 통계는 공개 여부와 관계없이 본인의 전체 독후감을 대상으로 유지합니다.
- 비정상 회원 상태의 팔로우 관계는 유지하지만 프로필 진입은 회원 상태 알림과 이전 화면 이동으로 제한합니다.
- 다른 사용자에게 노출되는 독서 목록은 독후감 공개 정책을 따릅니다.

## 알림 연계

- 알림 발신자 닉네임은 로그인 시 Redis에 저장된 값을 사용합니다.
- 좋아요 API의 독후감 작성자와 독후감별 알림 설정은 클라이언트 값을 신뢰하지 않고 서버가 독후감에서 조회합니다.
- 독후감 댓글 및 답글 알림도 서버가 독후감 원문 댓글 알림 여부를 확인한 뒤 설정이 `Y`인 경우에만 생성합니다.
- Redis 발신자 정보가 없으면 핵심 팔로우 또는 좋아요 업무는 유지하고 부가 알림만 생략합니다.
- 본인 사진의 좋아요·댓글·답글 알림은 마이페이지의 현재 사진 반응으로 이동합니다.
- 타인 사진에 남긴 댓글·답글 관련 알림은 사진 소유자의 공개 프로필에서 현재 사진을 열고, 댓글 번호가 있으면 해당 댓글을 강조합니다.
- 사진 알림은 클릭 시점의 팔로우 관계를 이동 조건으로 사용하지 않으므로 알림 생성 뒤 언팔로우해도 현재 사진이 유지되고 양쪽 계정이 정상 이용 중이면 접근할 수 있습니다.
- 사진이 교체·삭제됐거나 사진 소유자가 정상 이용 상태가 아니면 알림 이동 주소를 제공하지 않습니다.
