# 소셜 정책

## 개요

- 목적: 다른 사용자 프로필과 소셜 상호작용에서 공개 데이터 범위와 집계 기준을 일관되게 유지합니다.
- 적용 범위: 팔로우, 좋아요, 프로필 독서 요약 및 소셜 알림입니다.
- 기준일: 2026-08-04

## 팔로우 상태

팔로우 관계는 방향이 있는 관계로 저장합니다.

| 조건 | 버튼 상태 |
| --- | --- |
| 나만 상대를 팔로우함 | `FOLLOWING(팔로잉)` |
| 나는 팔로우하지 않고 상대만 나를 팔로우함 | `상호 팔로우 관계(맞팔로우)` |
| 양쪽 모두 팔로우하지 않음 | `FOLLOW(팔로우)` |
| 양쪽 모두 서로를 팔로우함 | `FRIEND(친구)` |

- `FRIEND(친구)` 버튼은 파란색 글자와 연한 하늘색 배경으로 표시합니다.
- 본인을 팔로우하는 요청은 허용하지 않습니다.
- 이미 존재하는 팔로우 요청은 중복 행을 만들지 않습니다.
- 언팔로우는 내가 상대를 팔로우한 방향만 삭제합니다.
- 상대가 나를 팔로우한 관계는 언팔로우 시 유지합니다.
- 새 팔로우 행이 실제로 생성된 경우에만 상대에게 알림을 생성합니다.
- 공개 독후감의 `관계순(기본순)`은 `FRIEND(친구)` 작성자, 로그인 사용자가 팔로우하는 작성자, 나머지 작성자 순으로 배치하고 같은 그룹은 최신순으로 정렬합니다.
- 사용자가 `최신순(최신순)`, `별점 내림차순(별점순)`, `좋아요 기능 설명(추천순)`을 선택하면 친구나 팔로우 관계를 반영하지 않고 선택한 기준만 적용합니다.
- 유지 중인 팔로우 관계라도 작성자가 `비활성화(계정 비활성화)`, `영구 탈퇴 대기(영구 탈퇴 유예)` 또는 `이용정지(이용 정지)`이면 해당 작성자의 독후감을 공개 목록과 우선 정렬에 사용하지 않습니다.

## 팔로우 및 팔로워 목록

- 마이페이지와 다른 사용자 프로필에서 팔로우 및 팔로워 목록을 제공합니다.
- 각 행에는 로그인 사용자 기준 팔로우 상태를 함께 제공합니다.
- 목록의 사용자가 로그인한 본인이면 팔로우 버튼을 표시하지 않습니다.
- `FRIEND(친구)` 관계인 회원을 SQL 정렬로 목록 상단에 우선 배치합니다.
- `이용정지(이용 정지)`, `비활성화(계정 비활성화)`, `영구 탈퇴 대기(영구 탈퇴 유예)` 회원은 회원 원본과 `사용자 팔로우 관계(팔로우 관계)`가 남아 있는 동안 목록에 노출합니다.
- 세 상태의 회원을 눌러 소셜 프로필에 진입하면 `사용자 계정 상태(회원 상태)` 코드와 코드명을 알림으로 표시하고, 사용자가 확인하면 이전 화면으로 이동합니다.
- 영구 탈퇴 유예기간이 지나 회원이 물리 삭제되면 양방향 `사용자 팔로우 관계(팔로우 관계)`를 삭제하고 팔로우·팔로워 목록에서도 완전히 제거합니다.
- 언팔로우 전에는 사용자 확인창을 표시합니다.

## 좋아요

- 좋아요는 대상 유형과 대상 번호 조합으로 대상을 식별합니다.
- 현재 사용자 기능에서 허용하는 대상 유형은 공개 독후감 `독후감`입니다.
- 좋아요 요청은 등록과 취소를 토글 방식으로 처리합니다.
- 좋아요를 새로 등록한 경우에만 독후감 작성자에게 알림을 생성합니다.
- 독후감 작성자가 해당 독후감의 좋아요 알림을 끈 경우 좋아요 행과 수 집계는 유지하고 신규 알림 저장과 푸시만 생략합니다.
- 좋아요 취소 시 알림을 새로 생성하지 않습니다.
- 본인이 작성한 독후감에 누른 좋아요는 본인에게 알림을 보내지 않습니다.
- 독후감 삭제 시 해당 독후감의 좋아요 데이터를 정리합니다.

## 프로필 공개 범위

- 다른 사용자 프로필에서 공개 독후감 기준 총 읽은 책과 받은 좋아요 수 및 팔로우와 팔로워 수를 제공합니다.
- 정상 이용 회원의 주간, 월간, 연간 독서 목표는 다른 사용자 프로필에 제공합니다.
- 다른 사용자 프로필의 총 읽은 책, 받은 좋아요, 독서량, 목표 달성 집계와 독서 목록에는 `독후감의 공개 여부 = 'Y'`인 공개 독후감만 반영합니다.
- `독후감의 공개 여부 = 'N'`인 비공개 독후감은 제목, 저자, 표지, ISBN, 기간 및 평점을 포함하여 다른 사용자 응답에 제공하지 않습니다.
- 본인 마이페이지의 독서 요약과 프로필 통계는 공개 여부와 관계없이 본인의 전체 독후감을 대상으로 유지합니다.
- 비정상 회원 상태의 팔로우 관계는 유지하지만 프로필 진입은 회원 상태 알림과 이전 화면 이동으로 제한합니다.
- 다른 사용자에게 노출되는 독서 목록은 독후감 공개 정책을 따릅니다.

## 알림 연계

- 알림 발신자 닉네임은 로그인 시 Redis에 저장된 값을 사용합니다.
- 좋아요 API의 독후감 작성자와 독후감별 알림 설정은 클라이언트 값을 신뢰하지 않고 서버가 독후감에서 조회합니다.
- 독후감 댓글 및 답글 알림도 서버가 독후감 원문 댓글 알림 여부를 확인한 뒤 설정이 `Y`인 경우에만 생성합니다.
- Redis 발신자 정보가 없으면 핵심 팔로우 또는 좋아요 업무는 유지하고 부가 알림만 생략합니다.
