# 설치형 웹앱 설치 권장 알럿 정책

## 개요

- 기준일은 2026년 8월 27일입니다.
- 정책 상태는 확정이며 사용자 웹과 데이터베이스에는 아직 적용하지 않았습니다.
- 웹 환경으로 로그인한 활성 회원에게 설치형 웹앱 설치를 권장하는 알럿을 계정 단위로 한 번 제공합니다.
- 실제 설치 여부와 설치 전환 행동은 수집하지 않으며 관리자 통계에도 제공하지 않습니다.

## 적용 대상

- 정상 로그인이 완료되고 최초 로그인 안내까지 마친 활성 회원에게 적용합니다.
- 비활성화 회원은 로그인 과정에서 계정 복귀를 먼저 처리하고 복귀 안내와 최초 화면 이동이 끝난 뒤 권장 조건을 판정합니다.
- 영구 탈퇴 대기와 이용정지 회원에게는 계정 제한 전용 화면을 우선 제공하며 설치를 권장하지 않습니다.
- 설치형 PWA로 실행 중인 화면에는 설치 권장 알럿을 표시하지 않습니다.

## 설치 권장 기준

1. 서버가 현재 로그인 계정의 설치 권장 알럿 확인 여부를 사용자 정보에 포함해 제공합니다.
2. 확인 이력이 없고 현재 화면이 일반 웹 환경이면 로그인 후 설치 권장 알럿을 표시합니다.
3. 사용자가 확인 버튼을 선택하면 서버에 최초 확인 일시를 저장합니다.
4. 확인 일시가 있으면 현재 접속 기기와 관계없이 설치 권장 알럿을 다시 표시하지 않습니다.
5. 설치형 PWA에서 실행 중이면 확인 일시와 관계없이 알럿을 표시하지 않습니다.

사용자가 확인하지 않고 화면이나 브라우저를 종료하면 확인 일시를 저장하지 않으며 다음 로그인에서 다시 표시할 수 있습니다.

## 알럿 동작

- 알럿에는 설치형 웹앱의 이용을 권장하는 제목과 짧은 설명을 표시합니다.
- 확인 버튼은 안내 확인 상태만 저장하고 알럿을 닫습니다.
- 확인 버튼으로 브라우저 설치 대화상자, 파일 다운로드 또는 앱 설치를 실행하지 않습니다.
- 브라우저별 설치 방법과 설치 가능 여부를 판정하거나 안내하지 않습니다.
- 확인 저장이 완료되기 전에는 성공으로 간주하지 않습니다.

## 데이터 저장

| 데이터 | 저장 위치 | 보존 기준 |
| --- | --- | --- |
| 설치 권장 알럿 최초 확인 일시 | 사용자 기본정보 | 계정 원본이 존재하는 동안 보존 |

- 별도 PWA 상태 테이블, 이벤트 이력 및 일별 집계를 생성하지 않습니다.
- 확인 일시가 없으면 권장 대상이고 값이 있으면 확인 완료로 판정합니다.
- 최초 확인 일시는 중복 요청으로 변경하지 않습니다.
- 설치 여부, 설치 시각, 플랫폼, 브라우저, 원본 User-Agent, IP 주소 및 기기 식별정보를 저장하지 않습니다.

## 계정 수명주기

### 계정 비활성화

- 기존 확인 일시를 사용자 기본정보와 함께 유지합니다.
- 비활성화 상태에는 설치 권장 알럿을 표시하거나 확인 일시를 변경하지 않습니다.
- 계정이 다시 활성화되면 기존 확인 일시를 그대로 사용합니다.

### 영구 탈퇴 대기와 취소

- 기본 30일 유예기간에는 확인 일시를 사용자 기본정보와 함께 유지합니다.
- 영구 탈퇴 대기 중에는 설치 권장 알럿을 표시하거나 확인 일시를 변경하지 않습니다.
- 유예기간 안에 탈퇴를 취소하면 별도 복원 없이 기존 확인 일시를 사용합니다.

### 영구 삭제

- 사용자 원본이 물리 삭제되면 확인 일시도 함께 삭제됩니다.
- 삭제된 확인 일시는 재가입한 새 계정에 연결하거나 복원하지 않습니다.

설치 권장 알럿은 서비스 알림을 생성하지 않으며 독후감 공개 설정, 댓글, 좋아요, 푸시 구독 및 소셜 관계를 변경하지 않습니다. 계정 수명주기의 단일 기준은 [계정 비활성화 및 영구 탈퇴 정책](withdrawal-policy.md)입니다.

## 실패 및 예외 처리

- 사용자 정보 조회가 실패하면 로그인과 사용자 정보 조회의 기존 공통 오류 흐름을 따릅니다.
- 확인 일시 저장이 실패하면 알럿을 닫지 않고 재시도 가능한 오류를 안내합니다.
- 동일 계정에서 확인 요청이 중복되면 최초 확인 일시를 유지하고 성공으로 응답합니다.
- 브라우저 종료나 화면 이동으로 요청이 완료되지 않으면 확인되지 않은 상태로 유지합니다.
- 설치형 PWA 실행 여부를 판정할 수 없으면 일반 웹 환경으로 간주하지 않고 해당 화면에서는 알럿을 생략합니다.

## 개인정보와 사용 제한

- 확인 요청에는 로그인 사용자 본인을 식별하는 기존 인증과 CSRF 검증을 적용합니다.
- 확인 일시는 설치 여부나 사용자의 설치 의향을 나타내는 값으로 해석하지 않습니다.
- 확인 일시는 권한, 계정 상태, 서비스 접근, 혜택 및 불이익을 결정하는 데 사용하지 않습니다.
- 관리자 화면과 통계 API에는 확인 일시와 관련 집계를 제공하지 않습니다.

## 제외 범위

- 브라우저 설치 대화상자 호출과 파일 다운로드
- 실제 PWA 설치, 설치 취소 및 제거 여부 감지
- 브라우저별 설치 방법 안내
- 설치 권장 노출과 닫기 이벤트 이력
- 설치 전환율과 플랫폼·브라우저별 통계
- 관리자 개별 회원 설치 권장 확인 이력 조회
- 설치 보상, 포인트 및 이벤트 캠페인
