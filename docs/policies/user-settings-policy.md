# 사용자 설정 정책

## 개요

- 목적: 사용자가 직접 선택할 수 있는 서비스 동작과 공개 범위 설정의 확정 및 미확정 기준을 관리합니다.
- 적용 범위: 프로필 사진과 배경사진 변경 활동의 팔로워 피드 노출 설정입니다.
- 기준일: 2026년 8월 27일입니다.
- 상태: 향후 구현을 위한 정책 메모이며 화면, API와 데이터 저장에는 아직 적용되지 않았습니다.

## 현재 동작

- 정상 이용 사용자가 현재 프로필 사진 또는 배경사진을 변경하면 현재 팔로워의 피드 조회 대상에 포함됩니다.
- 피드 노출 여부를 사용자가 선택하는 설정 화면과 저장값은 아직 없습니다.
- 공개 프로필에서는 팔로우 여부와 관계없이 현재 사진의 좋아요와 댓글을 사용할 수 있으며, 향후 피드 노출 설정은 이 공개 프로필 반응 범위를 변경하지 않습니다.

## 예정 설정

- 사용자는 자신의 프로필 사진 또는 배경사진 변경 활동을 팔로워 피드에 표시할지 선택할 수 있어야 합니다.
- 서버는 피드 조회 시 클라이언트 전달값이 아니라 사진 소유자가 저장한 최신 설정을 기준으로 사진 변경 카드를 포함하거나 제외해야 합니다.
- 설정을 끄더라도 현재 사진 파일, 공개 프로필 표시, 기존 좋아요·댓글과 사진 관련 알림을 삭제하지 않습니다.
- 설정을 다시 켜도 과거 사진 변경 활동을 피드에 소급 노출할지는 아직 확정하지 않았습니다.

## 미확정 항목

다음 항목은 설정 기능 구현 전에 사용자와 추가로 확정해야 합니다.

| 항목 | 미확정 내용 |
| --- | --- |
| 설정 단위 | 프로필 사진과 배경사진을 각각 설정할지 하나의 사진 변경 설정으로 묶을지 여부 |
| 기본값 | 신규 사용자와 기존 사용자의 최초 피드 노출 설정값 |
| 적용 시점 | 설정 변경 이후 사진부터 적용할지 현재 사진 활동에도 즉시 적용할지 여부 |
| 소급 노출 | 설정을 다시 켰을 때 과거 변경 활동을 피드에 다시 표시할지 여부 |
| 계정 비활성화 | 설정값을 보존하고 복귀 시 재사용할지 초기화할지 여부 |
| 영구 탈퇴 대기 | 유예기간 중 설정값 보존 및 취소 시 복원 여부 |
| 영구 삭제 | 사용자 원본 삭제 시 설정값의 물리 삭제 범위 |

## 실패 처리

- 설정 저장에 실패하면 화면의 선택 상태를 서버에 저장된 기존 값으로 되돌리고 실패를 안내해야 합니다.
- 피드 조회 중 설정 확인에 실패하면 비공개를 우선할지 기존 동작을 유지할지 구현 전에 확정해야 합니다.
- 여러 기기에서 동시에 설정을 변경하면 서버가 마지막으로 확정한 값을 모든 화면의 기준으로 사용해야 합니다.

## 구현 예정 근거

- 설정 화면: `src/main/frontend/src/pages/Settings`
- 프로필 사진 변경 화면: `src/main/frontend/src/pages/My/ProfileEditPage.tsx`
- 팔로잉 피드 화면: `src/main/frontend/src/pages/Feed/FeedPage.tsx`
- 사용자 설정 저장 영역: `src/main/java/org/our/sadari/user`
- 피드 조회 영역: `src/main/java/org/our/sadari/feed`
