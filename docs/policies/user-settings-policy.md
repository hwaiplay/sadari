# 사용자 설정 기능 기획서

## 개요

- 목적: 사용자가 알림 수신 범위, 공개 범위 및 새 독후감의 기본값을 한 곳에서 관리할 수 있도록 기능 기준을 정의합니다.
- 적용 대상: 정상 이용 중인 로그인 사용자입니다.
- 적용 범위: 사용자 설정 화면, 알림센터, 현재 기기 푸시, 공개 프로필, 팔로워 피드 및 독후감 등록·수정 화면입니다.
- 기준일: 2026년 9월 1일입니다.
- 상태: 사용자 화면, API, 데이터 저장과 알림·공개 범위 적용이 구현되었습니다.

## 핵심 원칙

- 사용자 설정은 회원별 단일 설정 데이터에서 관리합니다.
- 알림센터는 사용자가 받은 소식을 보관하는 영역이고, 푸시는 현재 기기로 소식을 전달하는 수단입니다.
- 알림 유형 설정은 알림센터 저장과 푸시 발송을 함께 제어하고, 현재 기기 푸시 설정은 푸시 발송만 제어합니다.
- 공개 범위와 새 콘텐츠 기본값은 구분합니다. 공개 범위 변경은 현재 노출에 적용하고, 기본값 변경은 이후 생성하는 콘텐츠의 초기값에만 적용합니다.
- 설정을 꺼도 좋아요, 댓글, 목표 및 사진 원본 같은 업무 데이터는 삭제하지 않습니다.
- 설정을 다시 켜도 꺼진 기간의 알림을 소급 생성하지 않습니다.
- 공개 범위와 알림 수신 가능 여부는 서버가 로그인 사용자와 저장된 최신 설정으로 다시 판정합니다.

## 설정 화면 구성

### 설정 메인

설정 메인에는 다음 메뉴를 표시합니다.

| 메뉴 | 목적 |
| --- | --- |
| 알림 설정 | 현재 기기 푸시와 알림 유형 및 새 독후감 알림 기본값을 관리합니다. |
| 공개 범위 | 독서 통계, 독서 목표와 사진 변경 활동의 공개 범위를 관리합니다. |
| 서비스 정보 | 기존 서비스 정보 화면으로 이동합니다. |
| 회원 탈퇴 | 기존 계정 비활성화 및 영구 탈퇴 화면으로 이동합니다. |

### 알림 설정

알림 설정 화면은 다음 순서로 구성합니다.

| 구역 | 설정 항목 | 설명 |
| --- | --- | --- |
| 현재 기기 | 이 기기에서 푸시 알림 받기 | 현재 브라우저 또는 설치형 웹앱의 푸시 연결만 켜거나 끕니다. |
| 활동 알림 | 좋아요 알림 받기 | 독후감, 현재 프로필·배경사진과 댓글·답글에 받은 좋아요 알림을 제어합니다. |
| 활동 알림 | 댓글·답글 알림 받기 | 내 독후감과 현재 사진의 댓글·답글 및 내 댓글에 달린 답글 알림을 제어합니다. |
| 활동 알림 | 새 팔로워 알림 받기 | 새 팔로워 알림을 제어합니다. |
| 활동 알림 | 독서모임 활동 알림 받기 | 모임 초대, 가입 신청 및 새 멤버 참여 같은 선택 가능한 활동 알림을 제어합니다. |
| 독서 알림 | 독서 종료일 리마인더 받기 | 목표 종료일이 지난 독후감의 리마인더를 제어합니다. |
| 새 독후감 기본 알림 | 좋아요 알림 기본값 | 이후 생성하는 독후감의 좋아요 알림 초기값을 정합니다. |
| 새 독후감 기본 알림 | 댓글 알림 기본값 | 이후 생성하는 독후감의 댓글 알림 초기값을 정합니다. |

현재 기기 푸시는 선택 즉시 권한 확인과 구독 변경을 실행합니다. 나머지 항목은 화면에서 변경한 뒤 하단의 `저장하기`로 한 번에 저장합니다.

### 공개 범위

공개 범위 화면은 다음 순서로 구성합니다.

| 구역 | 설정 항목 | 설명 |
| --- | --- | --- |
| 내 프로필 공개 범위 | 독서 통계 공개 | 독서 잔디, 독서 상태 비율과 기간별 상세 통계를 공개합니다. |
| 내 프로필 공개 범위 | 독서 목표 공개 | 주간·월간·연간 목표, 완료 권수와 달성률을 공개합니다. |
| 팔로워 피드 공개 범위 | 사진 변경 활동 피드 표시 | 현재 프로필 사진과 배경사진의 변경 활동을 팔로워 피드에 표시합니다. |
| 새 독후감 기본 공개 | 새 독후감을 공개로 작성 | 이후 생성하는 독후감의 공개 여부 초기값을 정합니다. |

모든 항목은 화면에서 변경한 뒤 하단의 `저장하기`로 한 번에 저장합니다.

## 알림 정책

### 알림센터와 푸시

알림센터에서는 푸시 켜기·끄기 버튼을 제공하지 않습니다. 알림 목록, 모두 지우기와 `알림 설정` 이동 기능만 제공합니다.

| 상태 | 알림센터 | 현재 기기 푸시 |
| --- | --- | --- |
| 해당 알림 유형 사용 | 새 알림을 저장합니다. | 현재 기기 푸시가 연결되어 있으면 발송합니다. |
| 해당 알림 유형 미사용 | 새 알림을 저장하지 않습니다. | 발송하지 않습니다. |
| 현재 기기 푸시 미사용 | 새 알림을 저장합니다. | 발송하지 않습니다. |
| 기기 알림 권한 차단 | 새 알림을 저장합니다. | 기기에서 표시할 수 없습니다. |

알림 유형을 끄기 전에 생성된 알림은 유지합니다. 다시 켜더라도 미사용 기간에 발생한 활동은 알림으로 소급 생성하지 않습니다.

### 현재 기기 푸시

- 현재 기기 푸시 상태는 기기 알림 권한과 현재 기기의 활성 구독을 함께 확인하여 표시합니다.
- 푸시를 켤 때 기기 알림 권한이 아직 결정되지 않았다면 사용자 클릭 직후 권한을 요청합니다.
- 기기에서 알림을 차단한 경우 앱에서 임의로 해제하지 않고 기기 설정 변경 방법을 안내합니다.
- 푸시를 끄면 현재 기기의 구독만 비활성화하고 다른 기기의 구독과 알림센터 알림은 유지합니다.
- 권한은 허용되어 있지만 구독이 없거나 만료된 경우 `연결되지 않음`으로 표시합니다.
- 현재 기기 푸시 변경은 브라우저 권한과 외부 메시징 토큰 처리가 필요하므로 다른 사용자 설정의 일괄 저장에 포함하지 않습니다.

### 알림 유형 판정

알림 설정은 알림 수신자를 기준으로 판정합니다.

| 활동 | 알림 생성 조건 |
| --- | --- |
| 내 독후감 원문에 받은 좋아요 | 수신자의 전체 좋아요 알림과 해당 독후감의 좋아요 알림이 모두 사용 상태입니다. |
| 내 현재 사진에 받은 좋아요 | 수신자의 전체 좋아요 알림이 사용 상태입니다. |
| 내 댓글·답글에 받은 좋아요 | 댓글 작성자의 전체 좋아요 알림이 사용 상태입니다. |
| 내 독후감에 받은 댓글·답글 | 수신자의 전체 댓글·답글 알림과 해당 독후감의 댓글 알림이 모두 사용 상태입니다. |
| 내 현재 사진에 받은 댓글·답글 | 수신자의 전체 댓글·답글 알림이 사용 상태입니다. |
| 내 댓글에 달린 답글 | 부모 댓글 작성자의 전체 댓글·답글 알림이 사용 상태입니다. |

다른 사람의 독후감에 작성한 댓글의 답글 알림은 독후감 소유자의 설정에 영향을 받지 않습니다. 댓글 좋아요는 좋아요 알림에 포함하고 댓글·답글 알림에는 포함하지 않습니다.

### 독후감별 알림과 새 독후감 기본값

- 새 독후감의 좋아요·댓글 알림은 저장된 기본값으로 시작합니다.
- 독후감 작성 화면에서 기본값을 확인하고 해당 독후감에 한해 변경할 수 있습니다.
- 기본값을 변경해도 기존 독후감의 설정은 변경하지 않습니다.
- 전체 알림을 끄더라도 독후감별 설정값은 유지합니다.
- 전체 알림을 다시 켜면 각 독후감에 보존된 설정을 다시 적용합니다.
- 독후감 상세에서 전체 설정 때문에 실제 수신이 중지된 경우 `전체 알림이 꺼져 있어 현재는 수신되지 않습니다.`라고 안내하고 알림 설정 화면으로 이동할 수 있게 합니다.

### 필수 알림

다음 알림은 사용자 알림 유형 설정과 관계없이 알림센터에 저장합니다.

- 본인이 신청한 독서모임 가입의 승인 또는 거절 결과
- 독서모임 강제 퇴장처럼 본인의 서비스 상태가 변경되는 안내
- 계정 이용 제한, 보안 및 운영상 반드시 확인해야 하는 안내

모임 초대, 모임장에게 전달되는 가입 신청 및 새 멤버 참여 같은 일반 활동은 독서모임 활동 알림 설정을 따릅니다. 필수 알림의 푸시 발송 여부는 현재 기기 푸시 연결 상태를 따릅니다.

### 타이머 알림

타이머 목표시간 설정은 사용자가 해당 세션의 알림을 명시적으로 요청한 것으로 봅니다. 별도의 전역 타이머 알림 설정은 제공하지 않습니다.

- 목표시간을 설정한 세션은 목표시간 도달 시 알림을 생성합니다.
- 현재 기기 푸시가 연결되어 있으면 푸시도 발송합니다.
- 현재 기기 푸시가 꺼져 있어도 알림센터에는 저장합니다.

## 공개 범위 정책

### 독서 통계와 독서 목표

독서 통계와 독서 목표의 공개 여부는 독립적으로 관리합니다.

| 독서 통계 | 독서 목표 | 공개 프로필 표시 |
| --- | --- | --- |
| 공개 | 공개 | 상세 통계와 목표·완료 권수·달성률을 모두 표시합니다. |
| 공개 | 비공개 | 상세 통계만 표시하고 목표와 달성률을 숨깁니다. |
| 비공개 | 공개 | 상세 통계를 숨기고 목표·완료 권수·달성률만 표시합니다. |
| 비공개 | 비공개 | 상세 통계와 목표 영역을 모두 숨깁니다. |

목표 공개는 완료 권수와 달성률을 포함하므로 독서 통계가 비공개여도 일부 집계값이 공개됩니다. 화면 도움말에서 이 범위를 명확하게 안내합니다.

- 본인은 공개 여부와 관계없이 자신의 통계와 목표를 확인할 수 있습니다.
- 다른 사용자는 서버가 저장된 공개 설정을 확인한 결과만 조회할 수 있습니다.
- 목표를 비공개로 설정하면 목표 권수, 설정 여부, 달성률, 누적 달성 횟수 및 이전 목표 비교값을 숨깁니다.
- 공개 독후감으로 계산할 수 있는 일반 독서 활동과 독후감 목록은 별도의 공개 정책을 따릅니다.
- 개인 독서 목표 공개 설정은 독서모임 회차 목표와 결과에 영향을 주지 않습니다.

### 사진 변경 활동 피드 표시

- 프로필 사진과 배경사진은 하나의 피드 표시 설정으로 관리합니다.
- 설정을 끄면 현재 프로필·배경사진 변경 카드를 팔로워 피드에서 즉시 제외합니다.
- 설정을 다시 켜면 현재 사진 변경 카드가 피드 조회 조건을 다시 충족할 수 있습니다.
- 이전 사진의 과거 변경 이력을 다시 생성하거나 별도 카드로 소급 노출하지 않습니다.
- 설정을 끄더라도 현재 사진 파일, 공개 프로필 표시, 기존 좋아요·댓글과 사진 관련 기존 알림은 삭제하지 않습니다.
- 공개 프로필에서 현재 사진에 반응할 수 있는 범위는 이 설정으로 변경하지 않습니다.
- 피드 조회 중 설정을 확인할 수 없으면 사진 변경 카드를 제외하여 비공개를 우선합니다.

### 새 독후감 공개 기본값

- 신규 사용자의 새 독후감 공개 기본값은 비공개입니다.
- 독후감 작성 화면은 사용자 기본값으로 공개 여부를 초기화합니다.
- 사용자는 작성 중 해당 독후감의 공개 여부를 변경할 수 있습니다.
- 기본값을 변경해도 기존 독후감의 공개 여부는 변경하지 않습니다.

| 독서 종료일 리마인더 | 사용 | 현재 알림 동작을 유지하기 위해 사용합니다. |
| 새 독후감 좋아요 알림 기본값 | 사용 | 현재 독후감 초기값을 유지하기 위해 사용합니다. |
| 새 독후감 댓글 알림 기본값 | 사용 | 현재 독후감 초기값을 유지하기 위해 사용합니다. |

- 신규 가입 시 회원별 설정 데이터를 함께 생성합니다.
- 기존 사용자에게 설정 데이터가 없으면 위의 기존 사용자 기준을 조회 기본값으로 사용합니다.
- 설정 데이터가 없는 기존 사용자가 처음 저장하면 전체 초기값을 포함한 설정 데이터를 생성합니다.
- 기존 사용자 기본값은 배포 전 데이터 보정 또는 서버의 명시적인 기본값 판정 중 한 가지 방식으로 일관되게 적용합니다.

## 저장 및 동시성

- 알림 설정과 공개 범위는 각각 독립된 저장 요청으로 처리합니다.
- 각 저장 요청은 해당 화면이 관리하는 항목만 변경하고 회원별 설정 전체를 덮어쓰지 않습니다.
- 서버는 허용된 설정 항목과 사용·미사용 값만 받아 검증합니다.
- 여러 기기에서 같은 항목을 변경하면 서버가 마지막으로 완료한 저장값을 최종값으로 사용합니다.
- 저장 성공 후 서버가 확정한 최신 설정을 화면에 반영합니다.
- 저장 실패 시 화면 선택값을 마지막 서버 확정값으로 되돌리고 실패를 안내합니다.
- 변경사항이 있는 상태에서 화면을 이탈하면 저장하지 않은 변경이 있음을 안내합니다.
- 현재 기기 푸시 변경과 일반 설정 저장은 별도 작업으로 실행하여 한쪽 실패가 다른 설정을 되돌리지 않게 합니다.

## 계정 수명주기

### 계정 비활성화 및 영구 탈퇴 대기

- 일반 설정 화면 접근과 새 알림 생성을 중지합니다.
- 독서 통계, 독서 목표와 사진 변경 활동 공개 설정을 비공개로 변경합니다.
- 비공개로 변경한 공개 설정은 계정 복귀 또는 영구 탈퇴 취소 시 자동 복원하지 않습니다.
- 알림 유형 선호, 새 독후감 공개 기본값과 새 독후감 알림 기본값은 보존합니다.
- 계정이 다시 활성화되면 보존한 알림 유형 선호에 따라 복귀 이후 발생한 새 알림만 생성합니다.
- 제한 전에 생성된 알림은 삭제 상태를 유지하고 복원하거나 재발송하지 않습니다.
- 모든 기기 푸시 구독은 비활성화하고 복귀 시 자동 복원하지 않습니다.
- 사용자가 복귀 후 현재 기기 푸시를 다시 명시적으로 켜야 합니다.
- 독서 목표와 설정값은 보존하되 제한 상태에서는 본인 및 타인에게 제공하지 않습니다.

### 영구 삭제

- 유예기간이 지나 계정이 물리 삭제되면 회원별 설정 데이터도 함께 삭제합니다.
- 삭제된 설정, 목표, 알림과 푸시 구독은 복구하지 않습니다.
- 다른 사용자의 알림 기록처럼 수신자에게 귀속되는 데이터는 해당 기능의 기존 보존 정책을 따릅니다.

## 실패 및 예외 처리

- 사용자 설정 조회에 실패하면 저장 화면을 임의의 기본값으로 활성화하지 않고 재시도를 안내합니다.
- 공개 범위 확인에 실패하면 다른 사용자에게는 비공개를 우선합니다.
- 알림 유형 확인에 실패하면 선택형 활동 알림은 생성하지 않고 필수 알림은 해당 업무 트랜잭션 정책에 따라 처리합니다.
- 푸시 구독 실패는 이미 저장된 알림센터 알림을 되돌리지 않습니다.
- 외부 메시징 서비스가 현재 기기 토큰을 사용할 수 없다고 응답하면 해당 구독을 비활성화합니다.
- 설정 저장과 콘텐츠 등록이 동시에 발생하면 각 요청이 서버에서 확정한 시점의 설정을 적용하며 이미 생성된 콘텐츠를 소급 변경하지 않습니다.

## 제외 범위

- 표시 언어 설정은 도서 정보 제공 범위와 현재 서비스 운영 언어를 고려하여 포함하지 않습니다.
- 글자 크기, 테마 및 자동 재생 같은 접근성·화면 환경 설정은 이번 범위에 포함하지 않습니다.
- 모든 기기의 푸시를 한 번에 제어하는 계정 단위 푸시 설정은 제공하지 않습니다.
- 과거 알림 소급 생성, 과거 사진 변경 카드 생성 및 기존 독후감 일괄 설정 변경은 제공하지 않습니다.
- 독서모임 회차 목표 공개 범위는 개인 독서 목표 설정에 포함하지 않습니다.

## 완료 조건

- 알림센터와 현재 기기 푸시의 역할이 화면 문구와 실제 동작에서 구분됩니다.
- 좋아요 및 댓글·답글 알림을 전체 또는 독후감별로 끌 수 있습니다.
- 새 독후감은 사용자 기본값으로 시작하고 기존 독후감은 영향을 받지 않습니다.
- 필수 모임·계정 알림은 선택형 알림 설정으로 차단되지 않습니다.
- 통계와 목표의 네 가지 공개 조합이 서버 검증과 공개 프로필에서 동일하게 동작합니다.
- 사진 피드 설정을 꺼도 공개 프로필 사진과 기존 반응 데이터가 유지됩니다.
- 현재 기기 푸시를 꺼도 알림센터에는 허용된 알림이 저장됩니다.
- 비활성화, 영구 탈퇴 대기, 복귀 및 영구 삭제 정책이 관련 정책 문서와 일치합니다.
- 설정 조회·저장 실패와 여러 기기 동시 변경에서 마지막 서버 확정값을 기준으로 화면이 복구됩니다.
