# 설치형 웹앱 자동 업데이트 정책

## 개요

- 기준일은 2026년 8월 6일입니다.
- 설치된 사다리 웹앱이 재설치 없이 최신 화면 코드, 스타일, 아이콘 및 공개 정적 이미지를 적용하는 기준을 정의합니다.
- 사용자 업로드 파일, 인증 정보, API 응답 및 계정 데이터는 자동 업데이트 캐시 범위에 포함하지 않습니다.

## 정상 업데이트

1. 웹앱을 시작하면 서비스워커 원본 캐시를 우회하여 최신 서비스워커를 확인합니다.
2. 새 서비스워커가 있으면 최신 기본 화면, Manifest 및 앱 아이콘을 새 버전 캐시에 저장합니다.
3. 새 서비스워커가 활성화되면 이전 사다리 앱 셸 캐시를 제거하되, 이미 열린 화면의 제어권은 강제로 변경하지 않습니다.
4. 새 서비스워커가 활성화되어도 현재 화면을 자동으로 갱신하지 않으며, 최신 앱 셸은 다음 앱 실행 또는 사용자의 명시적인 화면 갱신부터 적용합니다.
5. 프로필 수정처럼 저장되지 않은 텍스트 또는 선택 파일은 서비스워커 업데이트와 관계없이 현재 화면에서 유지합니다.
6. 내용 해시가 포함된 빌드 자원은 캐시를 우선하고, 같은 URL로 교체될 수 있는 아이콘·폰트·화면 이미지는 네트워크를 우선합니다.

## 홈 화면 아이콘

- Android Chrome이 새 아이콘을 변경 사항으로 인식할 수 있도록 Manifest의 아이콘 URL에 버전 식별값을 포함합니다.
- 아이콘 원본을 변경할 때는 해당 URL의 버전 식별값과 서비스워커 앱 셸 목록을 함께 변경합니다.
- 브라우저가 앱 이름이나 아이콘 변경을 보안상 중요한 변경으로 판단하면 사용자에게 업데이트 확인을 요구할 수 있습니다.
- 브라우저 또는 운영체제의 아이콘 적용 시점은 브라우저 정책에 따라 달라질 수 있으며 재설치를 기본 업데이트 절차로 사용하지 않습니다.

## 캐시 범위

| 대상 | 정책 | 이유 |
| --- | --- | --- |
| 화면 이동 HTML | 네트워크 우선 | 새 배포 화면을 즉시 적용하고 장애 때만 앱 셸을 사용합니다. |
| `/assets/` | 캐시 우선 | Vite 내용 해시가 변경되면 파일 URL도 변경됩니다. |
| `/favicon/`, `/fonts/`, `/img/` | 네트워크 우선 | 같은 URL의 정적 파일이 교체될 수 있습니다. |
| `/api`, `/uploads` | 캐시 제외 | 인증 상태와 사용자별 최신 데이터를 보존합니다. |
| 외부 출처 자원 | 서비스워커 캐시 제외 | 외부 제공자의 캐시 정책을 유지합니다. |

## 실패 처리와 복구

- 서비스워커 확인이 실패해도 현재 웹 화면 사용을 중단하지 않습니다.
- 새 앱 셸 저장이 실패하면 기존 서비스워커와 기존 캐시를 유지합니다.
- 서비스워커 제어권 변경으로 현재 화면을 자동 갱신하지 않아 선택 파일과 입력값이 초기화되지 않게 합니다.
- 네트워크 요청이 실패하면 저장된 화면 또는 정적 자원이 있을 때만 오프라인 응답을 제공합니다.
- 캐시에도 자원이 없으면 브라우저의 표준 네트워크 오류로 처리합니다.
- 앱 셸이 열린 뒤 표시하는 전역 화면의 조건은 [전역 연결 오류 화면 정책](connection-error-screen-policy.md)을 따릅니다.
- 잘못된 정적 리소스가 배포되면 서비스워커 캐시 버전과 아이콘 URL 버전을 올려 수정 자원을 다시 배포합니다.

## 계정 수명주기

- 업데이트 확인은 `활성`, `비활성화`, `이용정지`, 영구 탈퇴 대기 상태와 무관하게 정적 리소스에만 적용합니다.
- 업데이트는 계정 접근 권한, 공개 범위, 데이터 보존·삭제, 알림, 푸시 구독 및 소셜 관계를 변경하지 않습니다.
- 제한 상태 회원은 업데이트 후에도 서버에서 확인한 최신 회원 상태에 맞는 전용 화면을 유지합니다.
- 비활성화 복귀 또는 영구 탈퇴 취소 시 업데이트 캐시를 근거로 사용자 데이터나 푸시 구독을 복원하지 않습니다.
