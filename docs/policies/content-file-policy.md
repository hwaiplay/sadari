# 콘텐츠 및 파일 정책

## 비속어 검사 대상

- 사용자 닉네임
- 사용자 한줄소개
- 독후감 내용

## 비속어 사전

- 차단어는 `BADX_WORD` 공통코드의 활성 상세코드에서 조회합니다.
- 정상 허용어는 `EXCP_WORD` 공통코드의 활성 상세코드에서 조회합니다.
- 비속어와 예외 사전을 메모리에 적재하며 캐시 유효시간은 10분입니다.
- 캐시 만료 시 한 스레드만 DB에서 사전을 다시 읽도록 동시성을 제어합니다.
- 조회한 사전으로 아호-코라식 탐색기를 만들어 한 번의 입력 탐색으로 여러 단어를 검사합니다.

## 우회 표현과 예외

- 공백을 삽입한 비속어를 탐지합니다.
- 비속어 사이에 숫자 또는 특수문자를 삽입한 우회 표현을 탐지합니다.
- 일반 한글이나 영문 글자가 비속어 사이에 들어간 경우는 자동 제거하지 않습니다.
- `보이지`처럼 정상 단어가 과도하게 차단되는 것을 방지합니다.
- `시발점`처럼 비속어 문자열을 포함하지만 허용어 사전에 등록된 더 넓은 정상 표현은 허용합니다.
- 여러 비속어가 동시에 탐지되면 사용자 안내 정확도를 위해 더 긴 단어를 우선합니다.
- 차단 시 감지한 비속어를 실패 메시지에 포함합니다.

## 닉네임

- 최초 로그인으로 가입되는 회원은 카카오 닉네임 대신 공통코드의 주어, 서술어, 동물 명사를 조합한 닉네임을 자동 발급받습니다.
- 자동 닉네임은 `조합 문구_가입연월순번` 형식이며 동일 문구와 연월 안에서 순번을 네 자리로 증가시킵니다.
- 닉네임 순번은 별도 발급 테이블의 행 잠금으로 동시 가입 요청을 직렬화하고 사용자 닉네임 유니크 제약조건으로 중복을 최종 차단합니다.
- 한글, 영문, 숫자와 문자 사이의 단일 공백, 언더바, 하이픈을 사용할 수 있습니다.
- 공백, 언더바, 하이픈은 닉네임의 처음과 끝 또는 다른 구분자와 연속해서 사용할 수 없습니다.
- 닉네임은 구분자를 포함해 최대 25자까지 입력할 수 있습니다.
- 닉네임 변경 시 서버에서 중복 여부를 검사합니다.
- 닉네임 비속어 검사를 통과해야 저장할 수 있습니다.
- 저장 성공 시 Redis의 로그인 사용자 닉네임도 즉시 변경합니다.

## 텍스트 입력

- 사용자 입력은 저장 전 일반 문자열로 정규화합니다.
- 독후감 본문은 UTF-8 기준 최대 4,000바이트입니다.
- 프론트엔드와 백엔드에서 같은 본문 길이 제한을 검증합니다.
- 프론트엔드 검증은 사용자 안내를 위한 것이며 최종 저장 판단은 백엔드 검증입니다.

## 이미지 업로드

- 사용자가 업로드할 수 있는 유형은 프로필 이미지와 배경 이미지입니다.
- 허용 파일 형식은 JPEG와 PNG입니다.
- 파일명이나 브라우저 Content-Type을 신뢰하지 않고 실제 파일 시그니처를 검사합니다.
- 시그니처와 이미지 디코더가 판별한 형식이 다르면 거부합니다.
- 이미지 디코딩이 가능해야 하며 너비, 높이, 전체 픽셀 수 제한을 통과해야 합니다.
- 기본 제한은 파일당 10MB, 최대 20,000,000픽셀, 한 변 최대 8,192픽셀입니다.
- 검증한 이미지는 픽셀만 새 이미지로 재인코딩해 메타데이터와 숨은 페이로드를 제거합니다.
- 저장 파일명은 서버가 결정한 확장자와 UUID로 생성합니다.
- 원본 파일명에서는 경로와 제어문자를 제거하고 최대 길이를 제한합니다.
- DB 트랜잭션이 롤백되면 먼저 저장된 실제 파일도 제거합니다.
- 외부 Kakao 프로필 이미지는 외부 다운로드 실패가 로그인 전체 실패로 이어지지 않도록 대체 경로 저장을 허용합니다.
