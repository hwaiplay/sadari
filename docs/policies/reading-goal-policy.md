# 독서 목표 정책

## 목표 유형

독서 목표는 주간, 월간, 연간 목표를 함께 관리합니다.

| 유형 | 목표 적용 기간 식별 방식 |
| --- | --- |
| 주간 | ISO 주차 기준의 연도와 주차 조합 |
| 월간 | 연도와 월 조합 |
| 연간 | 연도 단위 |

- 주간 기준은 월요일부터 일요일까지의 ISO 주차입니다.
- 연말과 연초가 겹치는 주는 ISO week-based-year를 사용합니다.
- 목표 권수는 1권 이상의 정수여야 합니다.
- 주간, 월간, 연간 중 하나라도 유효하지 않으면 전체 저장을 거절합니다.

## 목표 변경

- 신규 목표 설정은 제한하지 않습니다.
- 기존 목표보다 높이는 변경은 횟수와 기간 제한 없이 허용합니다.
- 기존 목표와 같은 값은 DB 갱신과 수정 횟수 증가를 생략합니다.
- 기존 목표보다 낮추는 변경에만 횟수와 마감일 제한을 적용합니다.

| 유형 | 목표 낮추기 허용 횟수 | 목표 낮추기 잠금 시점 |
| --- | ---: | --- |
| 주간 | 1회 | 해당 주 종료일까지 3일 이하가 남은 시점 |
| 월간 | 3회 | 해당 월 종료일까지 7일 이하가 남은 시점 |
| 연간 | 5회 | 12월 1일부터 |

- 화면에는 유형별 남은 변경 횟수와 변경 가능한 잔여 일수를 표시합니다.
- 제한을 초과한 목표 낮추기 요청은 서버에서도 거절합니다.
- 목표 내리기 도움말의 목록 문구는 사용자 안내 팝업 콘텐츠의 `PROFILE`·목표 하향 조정 안내 행에 있는 첫 번째 콘텐츠 영역에서 조회합니다.
- 콘텐츠가 없거나 조회 및 JSON 검증에 실패하면 화면에 포함된 현재 기본 문구를 표시합니다.
- 팝업 콘텐츠의 저장, 조회 및 계정 수명주기 기준은 [사용자 안내 팝업 콘텐츠 정책](popup-content-policy.md)을 따릅니다.

## 이전 목표 가져오기

- 현재 주간·월간·연간 목표 중 비어 있는 유형만 복사 대상입니다.
- 각각 지난주, 지난달, 작년의 목표 권수를 조회합니다.
- 직전 목표가 없거나 0 이하이면 해당 유형은 건너뜁니다.
- 이미 현재 목표가 있으면 덮어쓰지 않습니다.
- 복사할 수 있는 목표가 하나도 없으면 실패로 처리합니다.
- 복사 성공 시 별도의 목표 설정 모달을 열지 않고 즉시 저장 완료 상태를 표시합니다.

## 달성률과 달성 횟수

- 달성률은 해당 기간의 `완독` 독후감 수를 목표 권수로 나누어 계산합니다.
- 화면 진행률은 100%를 초과해도 최대 100%로 표시합니다.
- 목표가 없거나 목표 권수가 0 이하이면 달성률은 0%입니다.
- 목표 달성 횟수는 과거 전체 주간·월간·연간 목표 중 완료 독후감 수가 목표 권수 이상인 기간을 집계합니다.
- 총 달성 횟수는 주간, 월간, 연간 달성 횟수의 합계입니다.
