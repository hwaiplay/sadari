# 관리자 사용자 통계 정책

## 개요

- 기준일: 2026-08-13
- 적용 대상: 사용자 통계 메뉴 권한을 가진 로그인 관리자
- 적용 화면: `/sadari/adm/statistics`
- 목적: 개인 식별정보를 노출하지 않고 사용자 규모, 활동, 정착과 이탈 흐름을 운영 지표로 제공합니다.

## 목적과 제공 범위

- 관리자 서버의 `/sadari/adm/statistics` 화면에서 개인 식별정보 없이 사용자 현황과 정착 및 이탈 지표를 제공합니다.
- 상태별 현재 회원 수, 신규 가입, 활동 추세, 일간·주간·월간 활성 회원과 30일·90일 미접속 회원을 제공합니다.
- 가입 후 재방문 유지율과 계정 이탈 추세를 제공합니다.
- 모든 지표는 별도 통계 테이블이나 스케줄러 없이 기존 업무 테이블을 실시간 조회하여 계산합니다.

## 집계 기준

- 유지율은 선택 기간과 동일한 길이를 유지하면서 1일, 7일과 30일 기준만큼 앞당긴 가입 코호트를 각각의 분모로 사용합니다.
- 1일, 7일과 30일 유지율은 가입 다음 날부터 각 기준 일수 안에 다시 로그인한 회원 비율입니다.
- 이탈 추세는 계정 비활성화 요청, 영구 탈퇴 요청, 관리자 이용 정지 시작과 계정 복구 완료 일자를 기준으로 계산합니다.
- 조회 기간은 관리자 화면의 `1개월`, `3개월`, `6개월`, `1년`으로 제한하며 각각 오늘을 포함한 30일, 90일, 180일, 365일을 조회합니다.
- 네 조회 기간은 모두 동일한 계정 상태 포함·제외 기준을 적용합니다.

## 계정 수명주기 처리

- 유지율은 조회 시점에 회원 원본이 남아 있는 전체 가입자를 대상으로 하며 `WITHDRAWN`과 `DELETE_PENDING` 회원을 포함합니다.
- 이탈 추세는 보존된 `TH_USWTHD`와 `TH_USSPND` 이력을 사용하므로 회원 원본이 물리 삭제된 뒤에도 남은 이력은 집계합니다.
- 물리 삭제가 완료된 회원은 회원 원본과 삭제된 활동 데이터가 필요한 통계에서 제외되어 동일한 과거 기간의 실시간 조회 결과가 달라질 수 있습니다.
- 통계 화면은 개인별 목록과 드릴다운을 제공하지 않으며 회원번호, 닉네임, OAuth 식별값, IP와 User-Agent를 응답에 포함하지 않습니다.

## 예외와 복구

- 관찰 기간이 지나지 않은 최근 가입자는 해당 기준과 동일한 기간 길이의 이전 가입 코호트로 대체하여 분모와 분자의 관찰 기간을 맞춥니다.
- 가입자가 없거나 관찰 가능한 가입자가 없으면 해당 비율은 0으로 표시합니다.
- 영구 탈퇴를 취소하고 회원 상태가 복구되면 복구 이후 로그인과 활동부터 실시간 통계에 다시 반영합니다.
- 탈퇴 과정에서 삭제된 댓글과 좋아요 및 비공개 처리된 콘텐츠는 계정 복구 뒤에도 자동 복원하지 않습니다. `TB_FOLLOW(팔로우 관계)`는 `WITHDRAWN(계정 비활성화)`와 `DELETE_PENDING(영구 탈퇴 유예)` 동안 유지하고 회원이 물리 삭제될 때만 제거합니다.
- 원천 조회가 실패하면 이전 조회값을 최신 통계처럼 저장하거나 표시하지 않고 관리자 공통 오류 응답을 제공합니다.

## 성능과 운영

- 통계 요청은 관리자 메뉴 권한 검증을 통과한 로그인 관리자만 실행할 수 있습니다.
- 원천 테이블의 조회 성능이 부족하면 먼저 날짜와 회원번호 기반 인덱스를 검토하며 별도 집계 테이블을 기본 해결책으로 사용하지 않습니다.
- 실시간 결과는 조회 시점의 원천 데이터와 현재 회원 상태를 기준으로 하며 영구 고정된 역사적 지표로 취급하지 않습니다.

## 상태와 처리 유형

| 구분 | 코드 | 통계 처리 |
| --- | --- | --- |
| 정상 회원 | `ACTIVE` | 상태별 회원 수와 일간·주간·월간 활성 회원 통계에 포함합니다. |
| 계정 비활성화 | `WITHDRAWN` | 남아 있는 가입자 원본을 유지율에 포함하고 이탈 추세에 요청을 기록합니다. |
| 영구 삭제 대기 | `DELETE_PENDING` | 남아 있는 가입자 원본을 유지율에 포함하고 이탈 추세에 요청을 기록합니다. |
| 이용 정지 | `SUSPENDED` | 상태별 회원 수와 이용 정지 시작일 이탈 추세에 포함합니다. |
| 계정 비활성화 유형 | `SOFT` | 계정 비활성화 요청 수로 집계합니다. |
| 영구 탈퇴 유형 | `HARD` | 영구 탈퇴 요청 수로 집계합니다. |
