# 마이페이지 독서 통계 정책

## 개요

- 기준일: 2026-08-21
- 적용 대상: `ACTIVE` 상태의 회원
- 적용 화면: 본인 마이페이지와 공개를 허용한 다른 사용자 프로필
- 목적: 기존 독서 시간과 독후감 데이터를 연도별로 시각화하고 공개 범위를 관리합니다.

## 제공 통계

| 통계 | 기간 | 원천 데이터 | 표시 기준 |
| --- | --- | --- | --- |
| 독서 시간 잔디 | 선택한 달력 연도 | `TB_RDATDX.READ_SECS` | 날짜별 타이머 확정 독서 시간을 다섯 단계 색상으로 표시하고 월 시작 열에 영문 세 글자 월명을 표시합니다. |
| 연속 독서 기록 | 현재 보존된 전체 기간 | `TB_RDATDX.READ_DATE`, `READ_SECS` | 타이머 확정 시간이 1초 이상인 날짜를 연결해 오늘 또는 어제까지 이어진 현재 연속일과 전체 최장 연속일을 표시합니다. |
| 독서 상태 비율 | 현재 보존된 전체 독후감 | `TM_REPORT.REPT_STAT` | 읽는 중, 완독, 중단 독후감 수를 목표 진행 막대 색상의 도넛그래프로 표시합니다. |
| 올해 가장 오래 읽은 책 | 서울 시간 기준 현재 연도 1월 1일부터 오늘 | `TM_RDTMRX.READ_SECS`, `TM_REPORT.REPT_NUMB`, `BOOK_NUMB`, `TM_BKINFO` | 완료된 타이머의 확정 시간을 책별로 합산해 상위 세 권만 표시합니다. 선택한 잔디 연도와 관계없이 항상 올해 기준이며, 본인 마이페이지에서는 항목을 누르면 연결된 독후감 상세로 이동합니다. 공개 프로필에서는 다른 회원의 비공개 독후감 접근을 만들지 않도록 통계 정보만 표시합니다. |
| 별점 분포 | 현재 보존된 전체 독후감 | `TM_REPORT.REPT_GRDE` | 유효한 양수 별점의 소수점을 버려 5점부터 0점까지 1점 단위 여섯 개의 막대로 표시합니다. 4.5점은 4점에, 실제 0.5점은 0점에 포함하며 저장된 무별점 값 0은 집계에서 제외합니다. 숫자 옆에는 별 아이콘을 표시하고 기록이 없는 별점도 0권으로 유지합니다. |
| 작년과 비교 | 현재 연도 1월 1일부터 오늘과 전년도 같은 날짜 범위 | `TB_RDATDX`, `TM_REPORT.REPT_STAT`, `REPT_ENDT` | 독서 시간, 독서일과 완독 권수를 나란히 표시하고 현재 연도에서 전년도를 뺀 증감을 표시합니다. |

독서 시간은 타이머로 확정된 시간만 포함합니다. 독후감의 시작일과 종료일로 시간을 추정하거나 타이머를 사용하지 않은 독서를 임의로 보완하지 않습니다. 기록이 없는 날짜는 0초로 표시하고 해당 연도 전체에 기록이 없어도 현재 연도의 잔디 구조는 유지합니다.

## 연도 조회 기준

- 기본 조회 연도는 서울 시간 기준 현재 연도입니다.
- 현재 연도는 1월 1일부터 오늘까지 표시합니다.
- 기록이 존재하는 과거 연도는 1월 1일부터 12월 31일까지 표시합니다.
- 조회 가능 연도 목록은 현재 연도와 `TB_RDATDX`에 기록이 존재하는 과거 연도로 구성하며 최근 연도부터 표시합니다.
- 현재 연도가 아닌 기록 없는 연도와 미래 연도는 조회하지 않습니다.
- 연도를 바꾸면 해당 연도의 날짜별 독서 시간만 다시 조회하고 독서 상태 비율은 현재 서재 전체 상태를 기준으로 제공합니다.
- 연속 독서 기록, 올해 가장 오래 읽은 책, 별점 분포와 작년 비교는 잔디 연도 선택과 별개인 고정 기준으로 제공합니다.

## 회원 설정

- 통계 카드 아래의 `공개 여부` 버튼으로 공개 여부를 변경합니다.
- 공개 여부의 기본값은 `N`이며, `Y`로 저장한 경우 다른 사용자가 공개 프로필에서 같은 통계를 볼 수 있습니다.
- 기존 회원처럼 `TM_USSETX` 행이 없는 회원은 `N`을 기본값으로 사용하고 첫 설정 저장 시 행을 생성합니다.
- 설정은 회원별 서비스 설정 마스터 `TM_USSETX.RSTA_YSNO`에 저장합니다. 알림 등 다른 회원 설정은 해당 기능 정책이 확정될 때 같은 회원 행에 별도 컬럼으로 확장합니다.
- `TM_USSETX`에는 독서 통계 원천이나 스냅샷을 저장하지 않습니다.

## 조회와 화면 처리

- 본인 조회는 공개 여부와 관계없이 로그인 회원의 통계를 제공합니다.
- 다른 사용자 조회는 서버가 `TM_USSETX.RSTA_YSNO = 'Y'`와 `TM_USERXM.USER_STAT = 'ACTIVE'`를 모두 확인한 경우에만 제공합니다.
- 비공개 또는 제한 상태 프로필은 통계 데이터와 설정 존재 여부를 구분하지 않는 빈 성공 응답을 반환하고 화면에 통계 카드를 남기지 않습니다.
- 마이페이지와 공개 프로필은 초기 진입 시 통계 SQL을 실행하지 않고 사용자가 통계 영역에 가까이 스크롤했을 때 한 번 조회합니다.
- 통계 영역 약 240픽셀 전에 조회를 시작하며 조회 실패는 해당 통계 카드 안에서 재시도합니다.
- 연속 기록, 책별 시간, 별점과 연도 비교 SQL도 같은 통계 카드가 화면 가까이 들어온 이후에만 실행합니다.
- 통계 카드는 목표 달성 횟수 카드와 같은 부모 화면의 좌우 14픽셀 여백 및 전체 너비를 사용합니다.
- 잔디가 화면 너비를 초과하면 가장 최근 날짜가 있는 우측 끝부터 표시하고 카드 내부에서만 가로 스크롤합니다. 최초 사용자 스크롤 전에는 프로필 수정 버튼과 같은 반투명 회색 안내를 잔디 위에 표시하고 스크롤 감지 후 천천히 숨깁니다. 가로 스크롤바는 조작 중에 표시하고 마지막 조작이 끝난 뒤 지연 페이드아웃합니다.
- 본인 화면의 `공개 여부` 버튼은 목표 수정 버튼과 같이 카드 테두리 바깥 우측 하단에 배치합니다.
- 조회 연도는 독서 잔디 제목과 같은 높이의 가장 오른쪽에 홈 화면과 같은 SelectBox 스타일로 표시합니다.
- 잔디 아래에는 `독서 타이머 기록을 기준으로 합니다.` 안내를 `적음`부터 `많음`까지의 색상 범례와 같은 행의 왼쪽에 표시합니다.
- 공개 설정 모달은 중복 소제목 없이 공개 안내 문구를 선택 버튼 위에 표시하며, 선택된 공개 범위는 초록 테두리와 옅은 초록 배경으로 구분합니다. 원형 닫기 버튼과 취소·저장 버튼의 배치는 독서 목표 설정 모달 스타일을 따릅니다.
- 잔디 색상은 0초 이상 10분 미만, 10분 이상 30분 미만, 30분 이상 1시간 미만, 1시간 이상 4시간 미만과 4시간 이상의 다섯 단계로 구분합니다.

## 독서 상태

| 코드 | 표시명 | 그래프 색상 | 통계 처리 |
| --- | --- | --- | --- |
| `DONE` | 완독 | `#9EDFC2` | 완료한 독후감 수에 포함합니다. |
| `READ` | 읽는 중 | `#F7D98B` | 현재 읽는 중인 독후감 수에 포함합니다. |
| `STOP` | 중단 | `#F4A7AD` | 중단한 독후감 수에 포함합니다. |

세 색상은 마이페이지 목표 진행 막대에서 사용하는 색상을 재사용합니다. 세 상태 중 데이터가 없는 상태도 0권으로 범례에 표시하고 허용된 세 상태 이외의 값은 포함하지 않습니다.

## 계정 수명주기

- `WITHDRAWN` 또는 `DELETE_PENDING` 전환 즉시 본인과 공개 프로필의 모든 연도 통계를 숨기고 `TM_USSETX.RSTA_YSNO`를 `N`으로 변경합니다.
- 설정 행이 없는 회원은 기본값이 이미 비공개이므로 별도 행을 생성하지 않습니다.
- 계정 비활성화 복귀 또는 영구 탈퇴 취소 후 `ACTIVE` 상태가 되어도 공개 여부를 자동 복원하지 않습니다. 회원이 공개 설정에서 다시 공개해야 합니다.
- 계정 제한 중에는 확정된 `TB_RDATDX`, 보존기간 안의 `TM_RDTMRX`와 `TM_REPORT`를 보존하며, 복귀 후 해당 원천으로 연도별 잔디, 연속 기록, 올해 책별 시간, 별점 분포, 독서 상태와 연도 비교 통계를 다시 계산합니다.
- 유예기간이 끝나 회원이 물리 삭제되면 `TM_USSETX`, `TB_RDATDX`, `TM_RDTMRX`, `TM_REPORT`의 회원 데이터를 삭제하고 복구하지 않습니다.
- 독서 통계를 위한 별도 개인 이력이나 스냅샷 테이블을 생성하지 않습니다.

상세 계정 기준은 [계정 비활성화 및 영구 탈퇴 정책](withdrawal-policy.md)을 따릅니다.
