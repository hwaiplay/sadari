## 문서 상태 기준

- `제안`은 구현 방향을 검토하기 위한 설계이며 소스와 데이터베이스에 아직 적용하지 않은 상태이다.
- `적용`은 관련 소스, 데이터베이스, 테스트 및 정책 문서에 반영된 상태이다.
- 설계가 구현되면 문서의 상태와 구현 근거를 같은 작업에서 갱신한다.
