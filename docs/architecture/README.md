# Sadari 아키텍처 및 설계 문서

## 문서 목록

| 문서 | 상태 | 주요 내용 |
| --- | --- | --- |
| [팔로잉 피드 기능 설계](following-feed-design.md) | 확정 설계, 기능 미구현 | 공개 완독·중단 독후감과 현재 프로필·배경사진 변경, 범용 좋아요·댓글·알림 연계 |

## 문서 상태 기준

- `제안`은 구현 방향을 검토하기 위한 설계이며 소스와 데이터베이스에 아직 적용하지 않은 상태이다.
- `적용`은 관련 소스, 데이터베이스, 테스트 및 정책 문서에 반영된 상태이다.
- 설계가 구현되면 문서의 상태와 구현 근거를 같은 작업에서 갱신한다.
